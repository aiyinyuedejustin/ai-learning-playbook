# 用 AI 学未知领域：效率、记忆与工具栈

> 汇总日：2026-10-11（Asia/Tokyo）  
> 素材：part-a（学习科学）+ part-b（社区）+ part-c（工具/拆章）  
> 结构：背景 → 框架 → 细节 → 怎么串 / 怎么魔改

## 1. 背景

记忆会衰减。第一天学 8 小时抬的是流畅感，不是存储强度。社区与论文同向：AI 砍「找资料、出题、排程」的摩擦；人保留「先检索、间隔、交错、费力讲回」。无护栏的 GPT 辅导，拿走 AI 后考试可掉约 17%（Bastani / PNAS）。

同叫 teach 至少三套：Matt=课程仓；pstack=代码费曼；Tutor=记忆闭环。可串，不可互相替代。

## 2. 框架（五层）

1. 对齐：MISSION / grill-me  
2. 地图：大 scope → syllabus 章节  
3. 授课：短课（Matt / ATC）+ 代码用 pstack  
4. 检索：当日测 + 次日讲回  
5. 调度：Anki / FSRS（跨周必备）

日循环建议 25–50 分钟，不是 8 小时 binge。

## 3. 必备 vs 可选

必备：MISSION、大纲、短课、检索练习、间隔复习、学习记录。  
领域强推：pstack（代码）、Absorber（长文）、grill（防跑偏）。  
可选：Obsidian、AnkiConnect、dashboard、SRSA、arena/Multica（学完后执行）。

## 4. 推荐串法

grill → anything-to-course 大纲 → 每章 Matt teach → 读代码 pstack → quiz → Anki/FSRS → 每周无 AI 迁移测 → 可选落地实现。
