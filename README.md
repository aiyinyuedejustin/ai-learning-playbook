# 用 AI 学新领域：效率、记忆与工具栈

碰到一个陌生领域，打开 AI 从早聊到晚，当天感觉学了很多，一周后却所剩无几。这不是 AI 讲得不好，而是这种学法正好踩中了记忆的几个弱点：记忆会衰减，流畅感会骗人，一次学完忘得最快。

这本小书讲怎么换一种方式和 AI 一起学：让 AI 承担找资料、出题、判分、排日程这些「不必要的难」，把回忆、讲解、动手、隔天再想起来这些「必要的难」留给自己，并且跨天、跨周坚持下去。材料来自学习科学研究（间隔效应、检索练习、合意困难）、AI 辅导的对照实验，以及 Reddit、Hacker News、X、linux.do、YouTube 上的实际用法和学习类 skill、工具。

全书由浅入深：背景与动机 → 整体框架 → 细节 → 意义与启示。
