# 画地图

目的：把一个主题拆成几级台阶，让用户知道总共有哪些东西、先后顺序是什么、自己现在站在哪一级。地图宁可粗一点，学的过程中再细化。

## 先读这些

- 主题文件夹里的 `goal.md`（终点和起点）、`gaps.md`（已知缺口）。
- 用户的 `preferences.md`，有就照它来。

## 步骤

1. **找资料，核对事实。** 不要只凭记忆排顺序。找两三份可靠资料核对：教材目录、官方文档、口碑好的入门教程或课程大纲。资料是视频时，先把字幕转成文字再读（见下面"视频资料"）。把用到的资料列在 `map.md` 末尾。

2. **拆成阶梯。** 按"学 B 之前要先懂 A"排成几层，每层一到三个节点：
   - 默认每个主题 5 到 12 个节点。小主题可以更少，大主题先拆成几个子主题，每个子主题各画一张，不要一张图塞几十个点。
   - 每个节点写一句"学完能做到什么"，不写空泛的标题。
   - 起点（`goal.md` 里写的）以下、用户已经会的节点，标成"已会"，不删，让用户看到全貌。
   - 学习顺序不必是项目驱动的。有的主题按概念层层往上，有的按"先会用、再懂原理"，看主题来定。

3. **用 Draw.io 画图，不用 Mermaid。** 生成一个原生 `.drawio` 文件（就是 mxGraphModel XML），从下往上或从左往右排层。
   - 有 drawio skill 就用它。官方开源的在 [jgraph/drawio-mcp](https://github.com/jgraph/drawio-mcp)，skill 文件是 `plugins/claude-code/skills/drawio/SKILL.md`，Claude Code、Codex、Cursor、Copilot 都有插件，不需要 MCP。
   - 没有 skill 也能做：直接写 XML。本目录 `assets/ladder-template.drawio` 是一个现成的阶梯模板，改文字和层数就行。
   - 装了 draw.io 桌面版就导出 PNG：`drawio -x -f png -s 2 -b 10 -o map.png map.drawio`。没有桌面版时，只交 `.drawio` 文件，用户可以在 app.diagrams.net 打开。
   - 中文要能显示。节点样式里写 `fontFamily=Noto Sans CJK SC;`（或者系统里有的中文字体），导出后打开 PNG 看一眼，确认没有方框乱码。
   - 状态用颜色区分：已会灰色，下一个要学的高亮，其余白色。
   - 写 XML 时注意三处容易出错的地方：节点文字里要换行，用 `&lt;br&gt;` 并在样式里加 `html=1`，不能直接写 `<br>`，否则 XML 不合法，导出时节点会整个消失；连线的样式里不要加 `whiteSpace=wrap`，否则连线上的文字会一个字一行竖着排；连线文字压住线条时，用 `<mxPoint as="offset">` 把文字挪开，再加 `labelBackgroundColor=#ffffff`。
   - 节点 id 用 `n1`、`n2` 这类简单编号，不要用 `map` 这样的常见英文单词，有的 id 会让导出直接失败。
   - 导出前先用任意 XML 解析器检查一遍文件能否解析；导出后打开图片看一眼，确认每个节点都在、文字没有挤在一起。

4. **写 `map.md`。** 内容依次是：
   - 图（`![地图](map.png)`，没有 PNG 就链接 `map.drawio`）；
   - 同样内容的表格，保证不看图也能读：层、节点、学完能做到什么、状态（已会 / 在学 / 未学 / 有缺口）；
   - 参考资料列表。

   表格同时就是进度表，`learn-track` 之后会更新它的"状态"一栏。

5. **请用户看一眼。** 问一句"顺序和范围对不对，有没有你特别想先学或者不想学的"。用户调整完再往下走。

## 学到一半卡住时

如果授课时发现用户缺一个地图上没有的前置知识，回到这里：在卡住的节点下面插一层，只补这一两个前置节点，不要重画整张图。补完在 `log.md` 里记一笔。

## 视频资料

你看不了视频，只能读文字。用 `video-transcript-sources` skill（或任何能拿字幕、没有字幕就语音转文字的办法）把视频变成带时间戳的文本，再引用。

## 做完以后

接 `learn-teach`，从第一个"未学"节点开始讲。
