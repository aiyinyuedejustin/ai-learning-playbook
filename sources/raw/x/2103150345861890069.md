## 正文

我最近发现一个很有意思的 Agent Skill：learn-from-materials。

它解决的不是“让 AI 帮你总结一份 PDF”，而是更进一步：把一堆资料真正变成一个可以继续学习的知识库。

你可以把书籍、PDF、PPT、Word、网页，甚至多份不同来源的材料一起丢给它。AI 会理解和整理这些内容，生成：

• 带出处、可追溯的知识库
• 可交互的离线学习网页
• 结构化 Markdown 笔记
• 针对重点内容的学习路径

我觉得最有意思的是“出处可追溯”。

普通 AI 总结经常有一个问题：看完答案，却不知道结论到底来自哪里。这个 Skill 会尽量把知识点和原始材料对应起来，学习时可以回到来源继续深挖。

而且它基于开放的 Agent Skills 规范，不绑定某一个 Agent。WorkBuddy、Codex、Claude Code、Copilot CLI 等支持 Skills 的客户端都可以使用。

安装也很简单，把 GitHub 项目 clone 到客户端的 skills 目录即可。

之后甚至只需要一句：

“请使用 learn-from-materials 系统学习这份 PDF，生成带出处的知识库、离线学习网页和 Markdown。”

第一次打开学习网页，还可以填写自己的职业和兴趣，让生成内容更贴近你的背景。

AI 阅读资料的下一步，可能不是替你读完，而是帮你真正学会。
