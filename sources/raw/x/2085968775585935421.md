## 长文：为什么 AI 时代还需要继续用 Anki

跟 ChatGPT 聊完，我会有种「这下懂了」的爽感
两周后再被问到同一个细节
脑子里经常只剩浆糊
模型讲得挺清楚
是我会忘
我现在的用法就一句
AI 负责学得快
Anki 负责忘得慢
下载：Anki
 
聊懂了，不等于记住了
我现在学东西，大量靠大模型
追问、举反例、当场考我
启动成本几乎为零
当场理解变强了
过一阵还是会忘
当场 quiz 只证明「这轮对话我跟上了」
证明不了「三个月后我还想得起来」
遗忘曲线没因为聊天学习而退休
它还是那个指数衰减的老东西
间隔重复干的事很土
在我快忘、还没全忘的时候
逼我主动回忆
先自己想，再翻面
别重读笔记，也别再开一轮长对话装复习
想不起来的那几秒很烦
烦的时候往往才在长记性
太顺、太流畅
常常是假掌握
还有一层以前低估了
工作里天天撞见的技能，会被动被间隔重复养住
我想刻意学新东西时，这招就失灵了
自己写卡又难
还没学会，写不出好问题
网上共享牌组多半是别人的课表
默认知识和我对不上
大模型补上了「随时开聊」
缺的是把聊透的结论
丢进一条会按日程再抽我脸的队列
「能查就行」关键时刻也不灵
写方案、拍板、跟人吵的时候
我要的是脑子里挂得住的框架
不是再开一个对话框
AI 几秒出摘要、出草稿
爽是当场到账的
间隔重复的回报在几周后
几乎看不见
人自然选前者
三个月后再付一次「重学税」
收成一句
解释过一次 ≠ 三个月后还能想起来
 
Anki 在我这儿是啥
Anki 不是背单词 App
是复习日程机器
生的多刷，熟的少刷
**我定记什么
它定何时再考我**
我会动的就这几块
牌组 别一次复习全世界
四个按钮 又忘了 / 勉强 / 顺利 / 太简单
同步 桌面免费；跨设备一般要 AnkiWeb；手机端各自看官方
插件 后面接 AI 靠它
体量 卡多也能跑；先把自己劝退的，往往是乱加卡
记忆从碰运气，变成可选择
AI 时代我改半句
可选的不再是「手写什么卡」
是「我审哪些 AI 卡」
界面丑
像上个年代的软件
我忍了
开源、数据在我这边、算法可调
我不想把每日复习绑在连胜和广告上
 
我也差点弃坑
方法科学，生活里照样停
有效时像失败
突击背很流畅，像会了
按间隔硬想就自我怀疑
人会逃回「再读一遍」
因为舒服
学校教的是突击
考前一周有效
毕业后还当学习默认值
欠卡螺旋
前几周加卡很快
漏一个周末，回来几百张
每张卡都在预约未来
债务长得比我快
工具变债主
好卡难做
AI 让出卡变便宜之后
新坑是垃圾进垃圾出
没过滤的卡又多又虚
技术正确，跟我无关
牌组一肥，动机先死
硬规矩
**制卡可以便宜
「决定记什么」不能便宜**
选题、改问题，本身就是学习
这步我不外包干净
 
分工：AI 打草稿，我终审，Anki 排期
 
 
最累的不是复习
是前置劳动
一个概念要炸成多张挖空、反向、对比
我会偷懒
Agent 最适合干这种「烦但有规矩」的活
两类我真在用
概念 / 公式 别只留一张「是什么」；再炸挖空、推导、易混对比
要刷手感的形式 语法变位、术语搭配——规则懂了，烦的是造情境；规则 + 几个种子词丢给 AI，我只复习
闪卡管不住手艺和判断力
读写说练另做
它只负责别把硬知识漏光
AnkiConnect 是关键螺丝
给本机 Anki 开本地接口
Agent 才能建组、加卡、查重
Anki 得开着
没有它，多半还在复制粘贴
自动化没意义
流水线五步
 
材料
AI 草稿（会忘且值得记）
我审
入库（手导或直写）
每天 5–10 分钟主动回忆
有人说制卡本身就是学习，不能全给 AI
我同意一半
**AI 出半成品
终审在我
跳过打字，不跳过思考**
 
路径 A：提示词 + 导入（我最常用）
别一上来就上 Agent
先验证这条链通不通
一句「根据下文做 Anki 卡」基本废物
懒提示出来的卡
太宽、不自包含、一张塞三点
或正确但我根本不在乎
我固定两段
先抽知识点清单（去水）
再压原子问答 / 挖空，锁死格式
进库前我几乎必改
AI 卡是半成品
心里过五问
六个月后还在乎吗
一张一个点吗
不看上下文能答吗
答案是不是太长
像不像编的
再加一句筛法
读完这篇，我会跟朋友讲啥
讲得清的那句，才进 Anki
提示词
 
导入，大约一分钟
TSV 几行 → 记事本 → 「.txt」（UTF-8）
先点开目标牌组
文件 → 导入
分隔符 Tab；映射正面 / 背面 / 标签
预览 1 张，再确认
第一周配额
**新增 ≤10 张/天
复习 ≤15 分钟**
 
路径 B：Anki 里的 LLM 插件
懒得切窗口
浏览卡时补一句解释
社区插件就行（如 Anki AI，码以插件页为准）
自备 API Key
账单在模型那边
插件只省切换
不发免审许可证
隐私和付费先扫一眼再绑料
 
路径 C：Agent 直连 Anki
已经在用 Claude Code / Cursor / Claude Desktop
值得把 Anki 接成「用说话管牌组」
底座 AnkiConnect
工具 → 插件 → 获取插件
代码常见 「2055492159」（以页面为准）
重启；Anki 保持运行
接口说明丢进项目 markdown
Agent 按文档干
别每次口头重讲
接上之后我喊它干啥
轻的
加卡、搜索、暂停、看今日量
重的
PDF 出 cloze、找难卡、批量改标签、查重、看缺口
一句话
**Anki 是账本
AI 是会用账本的操作员**
轻量示例（以 README 为准，命令会变）
$ claude mcp add anki -- uvx anki-mcp
Claude Desktop 挂本地 MCP
npm 上还有更重的封装
都要求 Anki + AnkiConnect
写进项目说明的默认规矩
 
先预览再写入
一键静默灌卡
技术爽，习惯死
材料侧
论文 / 视频纪要 → Agent 提炼 → 预览入库 → 我终审 + 每日短复习
链路一通
Anki 就不像另一个要伺候的 App
像流水线最后一站
 
怎么避免被 Anki 劝退
第一周别调参 默认够用；FSRS 以后再说，别掉进设置地狱
绑旧习惯 通勤 / 午饭后 / 睡前，钉一个
先清复习，再加新卡 欠卡就减新增
欠卡急救 暂停垃圾组；难卡先停或重写；每天只清固定分钟
成功标准要小 连续 7 天打开且没被欠卡劝退
不是建完人生知识库
 
今晚只做一件
别设计知识操作系统
apps.ankiweb.net 装桌面版
最近跟 AI 聊透、怕两周后忘掉的一个结论 → 3 张原子卡
明天按提示复习
我只守两句
**先预览再入库
每天打开 Anki**
差的往往不是模型
是有没有把「学过的一点」接进队列
让一张卡在未来某天
准时把问题扔回我脸上
AI 我继续用
Anki 我也会继续打开
