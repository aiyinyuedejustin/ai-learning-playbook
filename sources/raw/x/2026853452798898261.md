## 长文：你读的东西，99%都白读了


去年我做了一个统计：过去12个月，我读了大约300篇论文、文章、研报。
然后我问自己：能清楚复述核心观点的，有多少？
答案让我很难受：不到30篇。

也就是说，我花了几百个小时的阅读时间，90%都"亏损"了。不是因为没认真读——每篇我都划了重点、写了笔记。但几周后再看，那些笔记对我来说像陌生人写的。
这不是我一个人的问题。这是所有知识工作者的通病：我们的瓶颈不是读得太少，而是忘得太快。
今天分享我用 Claude Code 搭建的一套知识系统。4 个 Skill，形成一个闭环飞轮，让每一次阅读都变成可检索、可复习、可复利的资产。已开源，文末附安装方式。

搭完这套系统后，我的阅读流程变成了这样：

**读一篇论文**：输入 `/read`，AI 像一个训练有素的研究者一样帮我拆解论证结构、评估方法论、标注逻辑漏洞。不是总结摘要，是真正的批判性阅读。
**读一篇商业文章**：输入 `/insights`，AI 像一个商业分析师一样帮我提取表面信息背后的深层逻辑和可迁移的商业模式。
**读完想留下来**：输入 `/note`，AI 把整个对话蒸馏成两层——一张"地图"（研究摘要，保留完整推理链）和一堆"石头"（原子卡片，每张只说一个概念）。自动存入 Obsidian。
**第二天早上**：输入 `/review`，AI 用间隔重复算法挑出该复习的卡片，出题、评分、自动排期。

整个过程不到5分钟。但这5分钟决定了知识是"看过"还是"真正属于我"。

为什么读完就忘？
 
在讲系统之前，先理解一下问题出在哪里。

传统的阅读流程是这样的：

**读 → 划重点 → 感觉自己懂了 → 几周后全忘了**

这个流程有三个致命问题：

**第一，没有主动加工。** 划重点给大脑一个"我学了"的错觉，但你只是在做信息的搬运工。真正的学习需要你**用自己的语言重新组织**信息。

**第二，没有原子化。** 你的笔记是一大坨文字，其中包含十几个概念混在一起。你没法单独复习"某一个概念"，也没法把它和其他知识连接起来。

**第三，没有复习。** 艾宾浩斯遗忘曲线不是鸡汤，是实验数据：**24小时后你会忘掉70%。** 但几乎没有人有一个系统来安排"什么时候该复习什么"。

这三个问题，就是我搭这套系统要解决的。


四个技能，一个飞轮
 
每个技能独立可用。但四个组合在一起，形成一个飞轮：**获取 → 分析 → 沉淀 → 巩固 → 获取...**

复习时发现的薄弱点，会反过来驱动你更有针对性地阅读。这就是"知识复利"的真正含义——**不是读得更多，而是留下更多。**

Skill 1：/read — 像研究者一样阅读

大多数人读论文的方式是"从头读到尾"。这是最低效的方式。

一个训练有素的研究者会这样读：

1. **先扫全貌** — 标题、摘要、图表、结论，2分钟建立地图
2. **再追论证** — 核心论点是什么？用什么证据支撑？逻辑链条是否严密？
3. **最后批判** — 哪些假设是隐含的？哪些结论超出了数据支持的范围？

`/read` 就是把这个专家级阅读流程自动化了。

你给它一篇论文（URL、PDF、粘贴的文本都行），它输出一份结构化分析报告：

- **论证架构** — 树状结构展示核心论点和支撑证据
- **方法论评估** — 研究设计的优势和局限
- **逻辑审查** — 自动检查循环论证、过度推广、相关≠因果等常见问题
- **关键数据** — 保留具体数字，不做模糊概括

它有两种模式：`quick`（5分钟速览）和 `deep`（完整精读）。

**关键点：它不是在帮你"省时间"。它是在帮你看到你自己读的时候会忽略的东西。**


Skill 2：/insights — 像分析师一样提取洞察

`/read` 是给学术论文用的。`/insights` 是给商业文章用的。

区别在于：论文要看**论证是否成立**，商业文章要看**作者没说出来的东西**。

你给它一篇文章，它不只告诉你"文章说了什么"，而是提取三层洞察：

1. **原文信号** — 文章中的关键数据或事实（证据层）
2. **深层逻辑** — 这个信号背后的商业逻辑是什么（分析层）
3. **可迁移模式** — 这个逻辑可以应用到哪些其他场景（价值层）

它还能根据你的关注点切换视角：
- `--focus ai`：聚焦 AI 切入机会
- `--focus strategy`：解读战略信号
- `--focus model`：拆解商业模式

**分析完自动存入 Obsidian。** 零操作成本，读完就是分析完了。


Skill 3：/note — 地图 + 石头

这是整个系统最核心的技能。

它解决的是"笔记做了等于没做"的问题。方法很简单：**每次产出两层。**

**第一层：地图（Map）**

一张完整的研究摘要卡片。保留对话的完整推理链——不是"提到了什么"，而是"为什么得出这个结论"。读这一张卡片，就能恢复80%的对话价值。

**第二层：石头（Stones）**

从地图中提取的原子卡片。每张只讲一个概念，可以脱离上下文独立理解。

**地图让石头有意义；石头让地图可链接。**

石头用 `【】` 标记关键术语（如 `【reward prediction error】`），用 `**粗体**` 标记核心结论。这些标记在 Obsidian 中自动成为双向链接的入口。

当你积累了100张石头，它们之间的链接网络就开始涌现。**你会发现不同领域的概念在底层是连通的。** 这种涌现，靠一大坨笔记永远不会出现。
 

Skill 4：/review — 让遗忘曲线为你工作

有了卡片不复习，等于没有。

`/review` 用的是 **FSRS-6 算法**——目前最先进的开源间隔重复算法。它会根据你每次的回答质量，动态计算每张卡片的最佳复习时间。

流程：

1. 自动扫描你的 Obsidian，发现新的原子卡片
2. 挑出今天该复习的卡片
3. AI 出题（两种模式随机切换）：
   4. **回忆模式**：给你卡片标题，让你凭记忆描述内容
   5. **提问模式**：从卡片内容中出一道具体的问题
4. 你回答后，AI 评分：Again / Hard / Good / Easy
5. 根据评分自动安排下次复习时间

**新卡片强制用提问模式**（你还没见过内容，回忆没意义）。
**老卡片随机切换**（防止你只记住了"答案的形状"而不是知识本身）。

每次复习结束，给你一个统计：今天复了几张、薄弱卡片是哪些、明天有几张到期。

**每天5-10分钟。** 但这5-10分钟的复合效果是指数级的。


安装：3分钟搞定

前提：你已经安装了 [Claude Code](https://docs.anthropic.com/claude-code) 和 [Obsidian](https://obsidian.md/)，并配置了 Obsidian MCP 服务器。

```bash
# 克隆仓库
git clone https://github.com/owenliang60-ship-it/skills.git

# 复制到 Claude Code 技能目录
cp -r skills/read ~/.claude/skills/read
cp -r skills/insights ~/.claude/skills/insights
cp -r skills/note ~/.claude/skills/note
cp -r skills/review ~/.claude/skills/review
```

完成。在任何 Claude Code 会话中直接使用：

```
/read https://arxiv.org/abs/...     # 精读一篇论文
/insights https://blog.com/...      # 从文章中提取商业洞察
/note                               # 把对话蒸馏成原子卡片
/review                             # 开始今天的间隔重复
```

无需额外依赖。`/review` 的 FSRS 引擎是纯 Python 标准库实现，不需要安装任何包。


## 一些设计选择

搭这套系统时做了几个关键决策，简单解释一下为什么：

**为什么用 Obsidian 而不是 Notion？**

本地优先。你的知识库是 Markdown 纯文本文件，存在你自己的电脑上，不上传任何云端。即使 Obsidian 停止服务，你的数据依然可用。

**为什么要分"地图"和"石头"两层？**

因为它们解决的是不同问题。地图保留上下文和推理链，让你能回忆"当时怎么想的"。石头是独立的知识原子，让你能复习和链接。单独做任何一层，都只有一半的价值。

**为什么用 FSRS 而不是 Anki 的 SM-2？**

FSRS-6 是 2023 年发布的新算法，在记忆预测准确率上显著优于 SM-2。而且它是纯 Python 实现，没有外部依赖，不需要安装 Anki。

**为什么做成 Claude Code Skill 而不是独立应用？**

因为知识获取发生在对话中。你和 AI 讨论完一篇论文，直接说"存笔记"，它就地蒸馏。不需要切换工具、复制粘贴、整理格式。**零摩擦是持续使用的关键。**


最后说点真话

工具永远是手段，不是目的。

这套系统能帮你结构化阅读、自动存笔记、定时复习——但它不能替你思考。

**AI 负责的是信息的加工和编排。你负责的是判断和连接。**

卡片上写着"【多巴胺】编码的是动机，不是愉悦"——这是信息。但当你在读一篇关于 AI Agent 激励设计的论文时，突然想到"这和多巴胺的逻辑一模一样"——这种跨领域的连接，只有你能做。

工具的价值是让你**有余力做这种连接**，而不是被信息收集和整理消耗殆尽。
