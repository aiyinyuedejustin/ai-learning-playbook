## 正文

15 things I do so AI doesn't make me DUMB:

1.) I think before I prompt
- I write 3 lines on how I'd solve it first
- Then I compare my plan with AI's

2.) I read every line it writes
- If I can't explain the code, I don't ship it

3.) I debug by hand once a week
- No AI. Just logs, breakpoints and my brain

4.) I ask "why" not just "how"
- "Why this approach over the other two?" teaches more than the answer

5.) I make AI quiz me
- "Ask me 5 questions to check I understood this"

6.) I build one thing a month from scratch
- No copilot. Blank file. Old-school struggle

7.) I write first then let AI edit
- Never the other way around. My voice stays mine

8.) I learn the fundamentals AI hides
- Networking, databases, memory, how systems fail

9.) I argue with it
- "What's wrong with this?" "What would a senior engineer reject?"

10.) I read the docs not just the summary
- AI summaries skip the edge cases that break production

11.) I explain what I learned in public
- If I can't post it clearly, I didn't really learn it

12.) I solve the first 20% alone
- Getting stuck is where the learning happens

13.) I review AI code like a stranger's PR
- Security, edge cases, naming, tests

14.) I keep a "what AI got wrong" note
- It's the fastest way to learn where my judgment matters

15.) I use AI to go deeper, not to skip
- "Explain this like I'm the one maintaining it for 5 years"

AI should make you faster at thinking.
Not replace the thinking.

Bookmark this + send it to a builder who hasn't written code without AI in months.
