# Anki + GPT-3 = \<3

I made a small Chrome extension that enables you to generate and create Anki notes while you read by leveraging GPT-3. I'm really excited about the power of LLMs to transform the way that people think - this is the most crude, surface level use case and I still find it useful.

Check it out [here](https://github.com/AndrewJudson/ankiextension) if you are interested!
