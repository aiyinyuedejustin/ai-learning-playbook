*   Obsidian

## [](https://linux.do/t/topic/1359955#p-11658507-h-2)学习流程

1.   **确定目标**：搞清楚学习的目的；知识图谱预扫描（询问 Claude：“为了实现这个目标，我必须掌握的前置知识（Prerequisites）和最容易踩的坑（Common Pitfalls）是什么？）
2.   **子目标拆分**：根据目标让ClaudeCode进行学习步骤拆分，确定plan之后开始进行编码
3.   **手动调试**：编码完成之后手动在idea中进行debug进行学习
4.   **主动输出**：学习过程中使用Obsidian进行输出，并手动实现一遍代码
5.   **查漏补缺**：将输出交付给ClaudeCode进行知识填充，对知识填充后看看自己哪一点没有关注到
6.   **巩固**：最后将整个过程中生成的文档传到NotebookLLM中进行总结，生成视频，闪卡等可以检验一下

* * *

之前学习新技术只能一点点翻看文档，没有代码学习来的更加直接快速。在AI的帮助下，可以直接看到技术的使用方法，能够能快的应用到代码中去。对学习的总结输出能够让理解更加的深刻。

真的很感谢人工智能的技术，让之前只能自己摸索的往前走，有了一个好的学习搭子。
