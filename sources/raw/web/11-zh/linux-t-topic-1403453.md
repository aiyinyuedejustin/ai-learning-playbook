**完全基于本地文件**（JSON + Markdown）的个人知识管理系统。与 Obsidian 或 Notion 不同，它最大的亮点是深度集成了 **Claude Code**，让你能够通过**自然语言**直接与知识库交互，完全脱离了传统 GUI 的束缚。

**核心特性：**

*   **![Image 3: :speaking_head:](https://linux.do/images/emoji/twemoji/speaking_head.png?v=15) 对话即操作**：不需要复杂的菜单，直接告诉 AI “帮我记一条关于 Docker 的笔记” 或 “复习一下昨天的内容”，它能自动理解意图并执行。
*   **![Image 4: :brain:](https://linux.do/images/emoji/twemoji/brain.png?v=15) AI 驱动学习**：内置了 **SuperMemo SM-2 间隔重复算法**和**费曼技巧**。AI 会化身“导师 Agent”，自动生成测验题，强制你通过输出来巩固输入。
*   **![Image 5: :robot:](https://linux.do/images/emoji/twemoji/robot.png?v=15) 多 Agent 协作**：系统包含 8 个专业 Agent（如知识架构师、搜索助手），能自动从 Google 抓取资料并整理成结构化笔记。
*   **![Image 6: :locked:](https://linux.do/images/emoji/twemoji/locked.png?v=15) 本地优先**：无数据库依赖，所有数据都在本地，隐私完全掌控在自己手中。

如果你是 CLI 爱好者，或者正在寻找一个高度 AI 化且注重隐私的知识库方案，这个项目绝对值得一试。
