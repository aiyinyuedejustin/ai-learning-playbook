# 全世界都知道费曼学习法，除了费曼自己

费曼学习法太有名了，你就算没用过，也一定听过。讽刺的是，好像全世界都知道费曼学习法——除了费曼自己。

[牛顿](https://zhida.zhihu.com/search?content_id=153709018&content_type=Article&match_order=1&q=%E7%89%9B%E9%A1%BF&zd_token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJ6aGlkYV9zZXJ2ZXIiLCJleHAiOjE3OTI0MDA1MTYsInEiOiLniZvpob8iLCJ6aGlkYV9zb3VyY2UiOiJlbnRpdHkiLCJjb250ZW50X2lkIjoxNTM3MDkwMTgsImNvbnRlbnRfdHlwZSI6IkFydGljbGUiLCJtYXRjaF9vcmRlciI6MSwiemRfdG9rZW4iOm51bGx9.L6k9VB5p5h-_WMHBrG6fJQx1GPDhmf2RxznjneLtmhI&zhida_source=entity)的脑袋没有被苹果砸过，[富兰克林](https://zhida.zhihu.com/search?content_id=153709018&content_type=Article&match_order=1&q=%E5%AF%8C%E5%85%B0%E5%85%8B%E6%9E%97&zd_token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJ6aGlkYV9zZXJ2ZXIiLCJleHAiOjE3OTI0MDA1MTYsInEiOiLlr4zlhbDlhYvmnpciLCJ6aGlkYV9zb3VyY2UiOiJlbnRpdHkiLCJjb250ZW50X2lkIjoxNTM3MDkwMTgsImNvbnRlbnRfdHlwZSI6IkFydGljbGUiLCJtYXRjaF9vcmRlciI6MSwiemRfdG9rZW4iOm51bGx9.yH4OAcIfgDemIVO0qgAEwhlwJKzopgYc1Ollo5GaCQA&zhida_source=entity)没有在雷雨天放过风筝，费曼，也没有提出费曼学习法。

![Image 12](https://pica.zhimg.com/v2-152a13390ab0d4fa60eabea31508eace_1440w.jpg)

请自行播放《名侦探柯南》经典破案插曲，我将带你一步步揭开这个弥天大谎。

“费曼学习法”到底源自哪里？在中文世界，“费曼学习法”最早是由加拿大人斯科特扬在《如何高效学习》中提出，这本书出版于2013年。

![Image 13](https://pica.zhimg.com/v2-7fe1e8803a47432c5f7441a6de3c6730_1440w.jpg)

追根溯源，我又查询了它的英文原版，2009年出版。对比两本书的目录，我发现了一个疑点。

中文版中凭空多出来了“整体性学习技术的实际运用——费曼技巧”一节，而在英文版中，不但没有这一节，没有提到[Feynman technique](https://zhida.zhihu.com/search?content_id=153709018&content_type=Article&match_order=1&q=Feynman+technique&zd_token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJ6aGlkYV9zZXJ2ZXIiLCJleHAiOjE3OTI0MDA1MTYsInEiOiJGZXlubWFuIHRlY2huaXF1ZSIsInpoaWRhX3NvdXJjZSI6ImVudGl0eSIsImNvbnRlbnRfaWQiOjE1MzcwOTAxOCwiY29udGVudF90eXBlIjoiQXJ0aWNsZSIsIm1hdGNoX29yZGVyIjoxLCJ6ZF90b2tlbiI6bnVsbH0.HJ_UzGEqvLs0LA7IGpsIl3x8hQOVOaoD-Xgg_Ud4yD8&zhida_source=entity)（[费曼技巧](https://zhida.zhihu.com/search?content_id=153709018&content_type=Article&match_order=2&q=%E8%B4%B9%E6%9B%BC%E6%8A%80%E5%B7%A7&zd_token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJ6aGlkYV9zZXJ2ZXIiLCJleHAiOjE3OTI0MDA1MTYsInEiOiLotLnmm7zmioDlt6ciLCJ6aGlkYV9zb3VyY2UiOiJlbnRpdHkiLCJjb250ZW50X2lkIjoxNTM3MDkwMTgsImNvbnRlbnRfdHlwZSI6IkFydGljbGUiLCJtYXRjaF9vcmRlciI6MiwiemRfdG9rZW4iOm51bGx9.p5gCHV7p-cYz9hhwFIYVD0neN33wRmyUxVxXM4uUhRg&zhida_source=entity)），甚至连费曼都没有提到。

![Image 14](https://picx.zhimg.com/v2-8d0b36986a4b5d5ba51abc33a06e1b2d_1440w.jpg)

这让我对费曼学习法产生了怀疑。2009年的英文版还没有费曼学习法，4年后，2013年的中文版中却把它加了进来，难道费曼学习法是在这段时间里诞生的？但是，费曼在1988年就去世了啊！

当然，还有另一种可能，费曼学习法在2009年之前就已经被提出了，只是斯科特扬没有把它收录到英文版中。

那就去查查维基百科吧，既然费曼学习法这么有名，一定会有介绍的。

但是，出乎我意料的是，维基百科中竟然没有费曼学习法的相关词条！这加深了我对“费曼学习法”真实性的怀疑。

![Image 15](https://pic2.zhimg.com/v2-7faea3fef83ddbb9acd92930e4634cdb_1440w.jpg)

这条线索断了，不过没关系，我们还有另外一条线索——斯科特扬。别忘了，他是最早在中文世界提出费曼学习法的人。

我找到了斯科特扬的官网，发现他在2011年9月1号的博客中，介绍了[费曼](https://zhida.zhihu.com/search?content_id=153709018&content_type=Article&match_order=20&q=%E8%B4%B9%E6%9B%BC&zd_token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJ6aGlkYV9zZXJ2ZXIiLCJleHAiOjE3OTI0MDA1MTYsInEiOiLotLnmm7wiLCJ6aGlkYV9zb3VyY2UiOiJlbnRpdHkiLCJjb250ZW50X2lkIjoxNTM3MDkwMTgsImNvbnRlbnRfdHlwZSI6IkFydGljbGUiLCJtYXRjaF9vcmRlciI6MjAsInpkX3Rva2VuIjpudWxsfQ.UsksklaeCi5j_GoxYVVkV-UYGDv_8Q7Qm40XxjhXCX0&zhida_source=entity)学习法，博客还有一段视频，上传时间是2011年8月22日。

这个时间很有意思。2009年英文版书籍中没有提到费曼学习法，2013年中文版书籍提出费曼学习法，2011年在博客中首次提出，正好在这两个时间点之间！

也就是说，很可能斯科特扬在2011年提出费曼学习法，2013年又把这个方法加入到新出版的中文版中。

![Image 16](https://pic1.zhimg.com/v2-55b6b03bd18227f8a5cc0f5c294dbd14_1440w.jpg)

当然，还有另外一个可能，在2011年之前，就已经有人提出费曼学习法了。

为了验证这个假设是否正确，我用谷歌检索1990年-2011年之间，包含费曼学习法的网页，只得到3个结果，都来自斯科特扬的官网。可以初步判定，“费曼学习法”就是由斯科特扬提出的。

![Image 17](https://pic3.zhimg.com/v2-5e6a4ff5a69041fd8f3fc8e17a5660f8_1440w.jpg)

单一证据的力量还是有点薄弱，需要[交叉验证](https://zhida.zhihu.com/search?content_id=153709018&content_type=Article&match_order=1&q=%E4%BA%A4%E5%8F%89%E9%AA%8C%E8%AF%81&zd_token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJ6aGlkYV9zZXJ2ZXIiLCJleHAiOjE3OTI0MDA1MTYsInEiOiLkuqTlj4npqozor4EiLCJ6aGlkYV9zb3VyY2UiOiJlbnRpdHkiLCJjb250ZW50X2lkIjoxNTM3MDkwMTgsImNvbnRlbnRfdHlwZSI6IkFydGljbGUiLCJtYXRjaF9vcmRlciI6MSwiemRfdG9rZW4iOm51bGx9.F-g6j5BbDLvle68ys_OdbqO_2NiZfDao3CTAc3C89gM&zhida_source=entity)。利用[谷歌趋势](https://zhida.zhihu.com/search?content_id=153709018&content_type=Article&match_order=1&q=%E8%B0%B7%E6%AD%8C%E8%B6%8B%E5%8A%BF&zd_token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJ6aGlkYV9zZXJ2ZXIiLCJleHAiOjE3OTI0MDA1MTYsInEiOiLosLfmrYzotovlir8iLCJ6aGlkYV9zb3VyY2UiOiJlbnRpdHkiLCJjb250ZW50X2lkIjoxNTM3MDkwMTgsImNvbnRlbnRfdHlwZSI6IkFydGljbGUiLCJtYXRjaF9vcmRlciI6MSwiemRfdG9rZW4iOm51bGx9.B2y5k1eAATbceWj8HQ-OndWbWNw1BhxbrsKVsSlJM_A&zhida_source=entity)，我发现“feynman technique”在2011年9月，搜索量突然增加，和斯科特扬发表博客的时间刚好吻合！

![Image 18](https://pic3.zhimg.com/v2-ba54370a9c747849ef631e6767522d72_1440w.jpg)

扬，你的狐狸尾巴被我抓住了！

最后，让我们把时间轴捋一下。2009年，斯科特扬的《Learn More Study Less》出版；

2011年8月22日，斯科特扬上传视频，介绍费曼学习法，此前网上并没有费曼学习法的相关信息；

2011年9月1日，[斯科特杨](https://zhida.zhihu.com/search?content_id=153709018&content_type=Article&match_order=1&q=%E6%96%AF%E7%A7%91%E7%89%B9%E6%9D%A8&zd_token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJ6aGlkYV9zZXJ2ZXIiLCJleHAiOjE3OTI0MDA1MTYsInEiOiLmlq_np5HnibnmnagiLCJ6aGlkYV9zb3VyY2UiOiJlbnRpdHkiLCJjb250ZW50X2lkIjoxNTM3MDkwMTgsImNvbnRlbnRfdHlwZSI6IkFydGljbGUiLCJtYXRjaF9vcmRlciI6MSwiemRfdG9rZW4iOm51bGx9.FJjT1qYzdRp170mQ-zvrogvftEScVojuEOv0m8ZrCFk&zhida_source=entity)在博客上提出费曼学习法，并且引用了上传的视频；

2013年，《Learn More Study Less》的中文版，《如何高效学习》出版，书中增加了“费曼技巧”一节。

![Image 19](https://pic4.zhimg.com/v2-ca588a988c1a8f73b93bb11b56088299_1440w.jpg)

由此，我得出结论，费曼学习法是斯科特扬假冒费曼之名提出的，作案动机就是借势。

随便提一句，有一件有趣的巧合，费曼1988年去世，[斯科特扬](https://zhida.zhihu.com/search?content_id=153709018&content_type=Article&match_order=12&q=%E6%96%AF%E7%A7%91%E7%89%B9%E6%89%AC&zd_token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJ6aGlkYV9zZXJ2ZXIiLCJleHAiOjE3OTI0MDA1MTYsInEiOiLmlq_np5HnibnmiawiLCJ6aGlkYV9zb3VyY2UiOiJlbnRpdHkiLCJjb250ZW50X2lkIjoxNTM3MDkwMTgsImNvbnRlbnRfdHlwZSI6IkFydGljbGUiLCJtYXRjaF9vcmRlciI6MTIsInpkX3Rva2VuIjpudWxsfQ.cQ1wvqXjxps1evImvfTJ49jDtTRRS_ZxGnEmlNuDdIc&zhida_source=entity)1988年出生。

我想的话，大多数是如此的。  
诚然，每一位大师每一位普通人都有各自的学习方法，学习别人的（学习方法）优点，补足自己的（同上）缺点，这本是无可厚非的。  
按目前的情况是，费曼技巧俨然成为“公认的”“终极的”“最神的”学习方法。  
究其原因，一方面是费曼本人（在这里不多赘述）以及费曼技巧的内核的确符合一些科学原理，再者，费曼本人也提到过以教代学（证据网上搜）。  
另一方面是学习者本身没有多少时间去研究什么学习方法（当然，大多数学习者想的是拿来就用就行），时间紧，压力大，心理焦虑等个人因素再加上大众传媒意识形态等社会因素。对此，可以说：“不火不行呀！”
