# 参考答案思维方式


## 刘澜视角（作者思维透镜）

> **体系定位**：本 skill 是"五项修炼"第二项——参考答案思维方式的方法落地（核心修炼）。
> **作者镜片**：参考答案镜片——世上没有标准答案，只有参考答案；连自己的答案也当参考。
> **招牌口诀**：所有问题先答"看情况"，并准备"怎么看情况"（用洞见分类）。
> **边界提醒**：刘澜自承"看情况"也接近标准、仍仅供"参考"——原理笃定，应用谦卑，别滑向相对主义。

## R — 原文 (Reading)

> "所谓参考答案思维方式，就是既要学习已有的答案，把它们作为参考，又不能把它们作为标准答案，即不能生搬硬套。六个主要策略：洞见分类、标准参考答案、互动学习、注重过程而非结果、发现隐含的假设、反过来想。"
> "一个深刻的真理的反面可能是另一个深刻的真理。"
>
> — 刘澜，《学会如何学习》前言、第82课（引玻尔）

> **三阶段模型**："第一个阶段是'标准答案思维方式'。这时，我们把家庭、学校、社会所教给我们的种种当作标准答案。第二个阶段是'参考答案思维方式1'。这时，我们把之前（及今后）家庭、学校、社会所教给我们的种种当作参考答案，并形成自己的答案。第三个阶段是'参考答案思维方式2'。这时，我们把自己的答案也当作参考答案，随着情境的不同而修改，并随着认识的改变而更新。"
>
> **一句口诀**："参考答案思维方式的口诀，三个字：**看情况**。如果说有一个简单的途径来培养参考答案思维方式，那就是嘴上多说看情况，脑子里多想看情况。"
>
> — 刘澜，《反向学习：学习力的五项修炼》第二章（机械工业出版社，2025）

## I — 方法论骨架 (Interpretation)

参考答案思维方式的底层判断是：**任何答案/道理都只在一定条件下成立，没有放之四海皆准的真理**。把任何答案当参考答案而非标准答案——可参考、可学习，但不可生搬硬套。这是对待一切道理的态度底座，是其他学习工具（四问学习法、发现模式）能起作用的前提。

《反向学习》给出了心智发展的**三阶段模型**作为顶层锚定：

1. **标准答案思维方式**（对应凯根"规范主导"）——把家庭、学校、社会教的当作标准答案。这是反向学习要"卸载"的起点。
2. **参考答案思维方式 1**（对应凯根"自主导向"）——把外来答案当参考答案，**形成自己的答案**。但自己的答案仍被当标准答案来守。
3. **参考答案思维方式 2**（对应凯根"内观自变"）——**把自己的答案也当参考答案**，随情境修改、随认识更新。这是本 skill 要带用户抵达的目标。

> 口诀**"看情况"**不是相对主义的和稀泥，而是要求你**紧接着说清"看什么情况"**——用具体模型/维度给出条件判断（如"智商重要还是情商重要？看情况：基层看技术能力，中层看人际能力，高层看概念能力"——卡茨模型）。

培养这种思维方式有六个主要策略，加上几个配套工具：

1. **洞见分类**——不用表面分类（"工作能力/生活能力"）装道理，用更深的分类（"技术/人际/概念能力"）重新组织。分类一变，看到的道理就变。
2. **标准参考答案**——某领域被广泛认可的基准答案，介于"标准答案"和"参考答案"之间。可作为起步，但不能停在它身上。
3. **互动学习**——通过讨论让不同参考答案相互碰撞、修正（见 `hudong-xuexi-talks`）。
4. **注重过程而非结果**——学作者推导过程而非只学结论；关注"形式"而非"内容"。作者自承本书即在此策略下写成（呈现思考过程，不只给结论）。
5. **发现隐含假设**——任何道理都建立在假设上，假设不一定成立。听到道理先问"它在什么前提下才对"。
6. **反过来想**——一个道理的反面往往也是对的（玻尔：深刻的真理反面可能是另一深刻的真理）。问"相反的道理在什么条件下也对"。

配套工具：

- **正反合**——若正反两个道理都成立，不能只说"看情况"，要找到把正反"合"成一个可操作模式的具体方式（如用管理者三大能力模型分层回答"智商重要还是情商重要"）。"一流头脑"认识到反面也对，"超一流头脑"能把相反道理合成一个可操作道理。
- **尚未心态**——把"未"（没有/不是）改写为"尚未"（暂时不是）。一字之差，从消极静止变积极动态。"我没有钱"→"我暂时没有钱"。
- **第四种谦虚 / 第四种骄傲**——今天的自己面对未来的自己要谦虚（我知道的不一定对），面对昨天的自己要骄傲（确实进步了）。学习是自己跟自己比，不是跟别人比。
- **假设检验**——把理所当然的结论当假设用证据检验；证据不能推翻假设，只能用新假设推翻旧假设。
- **多种解释**——面对同一现象强迫自己设想多个解释，避免单一解释（如"他喜欢上别人了"）破坏关系或遮蔽真相。所有解释都是待检验的假设。

## A1 — 书中的应用 (Past Application)

### 案例 1: 作者"体温"概念的演化留痕（注重过程而非结果）

- **问题**: 作者如何让读者真正学到"参考答案思维方式"本身，而不只是学到一条条结论？
- **方法论的使用**: 用策略4"注重过程而非结果"。作者把自己对"学习体温"概念的思考轨迹完整留痕：先提出"两种带着体温学习的方式"（用身体辅助 / 用身体落实），再改为"两种体温"（思考的体温 / 行动的体温），再改为"三种体温"（认知 / 情感 / 行为），最后又提出"困惑的体温"。每一次修正都呈现给读者，而不是只给最终版本。
- **结论**: 读者学到的不仅是"体温"这个最终概念，更是"作者如何思考体温"的过程——也就是参考答案思维方式本身的示范。
- **结果**: 作者明示这是"推动你应用参考答案思维方式的一个重要策略：注重过程而非结果"。本书的整个孕育过程（语音点评 → 文字稿 → 成书）都是这一策略的示范。

### 案例 2: YGB 同学"行百里者半九十"——有正反无合，作者补"合"（反过来想 + 正反合）

- **问题**: YGB 同学分享"行百里者半九十"对他触动很大，并主动反过来想——有时"万事开头难"，所以资源配置有时应前轻后重、有时应前重后轻。这算不算很好的参考答案思维方式？
- **方法论的使用**: 用策略6"反过来想" + 配套工具"正反合"。YGB 做到了"正"（行百里者半九十 → 前轻后重）和"反"（万事开头难 → 前重后轻），但作者指出他**没有"合"**——没有提出一个可操作的方案：怎么知道什么时候该前轻后重，什么时候该前重后轻？作者示范"合"：用管理者三大能力模型的分层思路（不同阶段、不同层级，关键变量不同），把两个相反道理合成一个可操作模式。
- **结论**: 反过来想不是相对主义（"相反才对"），而是寻找条件的边界；正反合不能停留在"看情况"，要找到把正反合在一起的具体方式。
- **结果**: 得到一个比单独"正"或"反"都更具操作性、逻辑自洽的更高层次模式——"超一流头脑"的标志。

### 案例 3: S 同学"运用自如"——第四种谦虚的诊断（ce15）

- **问题**: S 同学说自己跟作者学习以来，对数个管理模型"了然于胸、运用自如"。作者为何感到惊讶并指出问题？
- **方法论的使用**: 用配套工具"第四种谦虚/骄傲" + "尚未心态"。S 同学的"运用自如"只是相对以前的自己而言，但她把相对进步当成了绝对掌握，处在低层次的"我知道我知道"。作者自己掌握得更好反而更多困惑——因为他更接近知识圆圈边界，接触到边界外的"我不知道"。正确姿态是：面对昨天的自己骄傲（确实进步了），面对未来的自己谦虚（未来的自己一定懂得更多，今天的信念可能被否定）。
- **结论**: 掌握得越浅越容易觉得"运用自如"，掌握得越深越能发现自己的"不知道"。把"我运用自如了"改写为"我尚未运用自如"——一字之差，从关闭学习变为打开学习。
- **结果**: 作者借此提出"第四种谦虚"概念，并联通第51课"学习是自己跟自己比"——唯一的比较是纵向的（今天 vs 昨天 / 今天 vs 明天），不是横向的（自己 vs 他人）。

### 案例 4: 王阳明"因病开方"——没有放之四海皆准的方子（对应 ce24）

- **问题**: 学生把王阳明平日答问的话记录下来要出书，王阳明为何反对？
- **方法论的使用**: 用策略5"发现隐含假设" + 整体参考答案思维方式。王阳明说："圣贤教人，就好像医生治病一样，是针对每个病人的具体情况开方拿药；你现在写下来，其他人会认为所有人都适合这个方子，那会医死人的。"——揭穿隐含假设：一个答案可以脱离具体情境普遍适用。这个假设不成立。
- **结论**: 别人的答案是针对别人的困惑开的方子，用到自己身上会"医死人"。必须产生自己的参考答案。困惑有体温（来自自己的实际问题），答案才准确；困惑太抽象，得到的答案只有一般性和简单性，但不知道怎么用。
- **结果**: 《传习录》《爱比克泰德论说集》虽非标准答案，但是精彩的参考答案——许多人会得同样的病，这些方子仍然有参考价值。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应引导用户按以下步骤走：

🔴 **CHECKPOINT · 起点确认**：激活后先复述用户此刻面对的"道理/答案/金句/模型"原句（一句话），并确认它的来源（老师？书本？权威？自己觉得掌握的？）。确认后再进入第 1 步——不要跳过，否则后续"发现假设"会落空。

1. **发现隐含假设** ★ 最关键
   - 听到任何道理/答案/金句，先问："它建立在什么隐含假设上？这个假设一定成立吗？"
   - 完成标准：能说出至少一个隐含假设，并能判断它在什么条件下不成立。
   - 判停条件：若用户说不出任何隐含假设，提示这可能是"把参考答案当标准答案"的信号（ce19），回到 R 段重读参考答案思维方式的定义。

2. **反过来想**
   - 问："相反的道理在什么条件下也对？"提示用户找一个相反的谚语/道理，并标出它成立的条件。
   - 完成标准：能给出一个相反道理及其成立条件，而非简单说"相反才对"（那是相对主义）。
   - 判停条件：若用户只能说"相反才对""反过来也一样"，却给不出相反道理成立的具体条件，提示这是相对主义滑落，回到 🔴 起点确认它到底在反驳哪条具体声称。

3. **正反合**
   - 若正反都成立，问："怎么把两个相反的道理合成一个可操作的模式？"明确拒绝"看情况"这种敷衍的合。
   - 完成标准：能给出一个具体的合成模式（如用某个分层模型把正反分配到不同条件），可在行动中落地。
   - 判停条件：若用户只能说"看情况"，提示这是有正反无合（YGB 同学的问题），需要找具体的合成方式。

4. **用"尚未"替代"未"，用第四种谦虚面对未来自己**
   - 若用户表达"我不会""我运用自如了"等判断，引导改写为"我尚未……"，并问："面对未来的自己，我现在的判断可能哪里会被否定？"
   - 完成标准：把至少一个静态判断改写为动态判断；能说出一个未来自己可能修正的点。
   - 判停条件：若用户拒绝改写（"我确实已经掌握了"），质疑式追问："你能举出一个这个模型在你具体情境里失效的案例吗？"举不出 → 多半是"运用自如"的虚假掌握（ce15），回到第 1 步重查隐含假设；举得出 → 承认边界，保留判断。

5. **关注过程而非结果**
   - 问："这个结论是怎么推导出来的？"而不只是"结论是什么？"提示用户复述作者的推导链条。
   - 完成标准：能复述推导过程，而非只复述结论。
   - 判停条件：若用户只能复述结论、说不清推导，提示这是"注重结果而非过程"，回到 R 段第 35 行重读策略4。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **纯事实查询**：用户只是想知道一个事实（"北京面积多少"），不需要六策略的反思。
- **紧急决策**：火警、急救、截止时刻的操作决策，来不及反思隐含假设——先行动后反思。
- **数学/逻辑证明**：演绎证明的结论是标准答案，不是参考答案；本 skill 的"反过来想"在数学里不适用（"1+1=2"的反面不对）。
- **机械记忆**：背单词、记公式时，先把基础记牢（垒基学习），再谈参考答案。

### 作者在书中警告的失败模式

- **把老师的答案当标准答案**（ce19）：引用老师的话作为最终答案，不质疑、不结合情境调整。第79课明示："即使老师本人说自己提供的是标准答案，你也要当作参考答案。"
- **从别人那里寻求标准答案**（ce24）：期待别人给一个放之四海皆准的答案，照搬别人的解决方案。王阳明"因病开方"——别人的方子用到自己身上会"医死人"。
- **让提问误导你**（ce30）：听到提问就急于回答，被提问预设的方向和前提带着走，不质疑问题本身。提问是"误导他人的好工具"。
- **"运用自如"的虚假掌握**（ce15）：自以为对某模型"运用自如"，实际只是低层次的"我知道我知道"。掌握越浅越易觉得掌握，掌握越深越发现"不知道"。

### 作者的盲点 / 时代局限

- **强依赖前作五项修炼体系**：参考答案思维方式是五项修炼之第二项的核心操作，独立读者可能不熟悉"模式""看家模式""标准参考答案"等术语——使用本 skill 时若用户不熟悉这些词，先用日常语言解释。
- **概念独创性边界模糊**：作者自创"第四种谦虚/骄傲""尚未心态""标准参考答案"等概念，但其与已有概念（批判性思维、成长型心智、辩证法）的边界未充分检视，部分判断依赖个人权威而非论证（"我就是这么认为的"）。
- **案例样本窄**：六策略的案例多来自企业管理者/创业者微信群学员，对学生、蓝领、自由职业者的适用性需用户自行迁移。

### 容易混淆的邻近方法论

- **批判性思维**：作者明示参考答案思维方式就是强批判性思维——"所有人的答案（包括自己的答案）都是参考答案"。但本 skill 更强调"**参考**"（可学习、可吸收），而批判性思维在中文语境里常被理解为"**批判**"（质疑、否定）。差别在姿态：本 skill 是先吸收再质疑，不是先否定。
- **辩证法（黑格尔正反合）**：本 skill 的"正反合"借黑格尔形式，但**不预设绝对精神的最终合**——合出来的仍是参考答案，可被未来的自己再推翻。本 skill 的合是操作性的（可落地行动），不是形而上学的。
- **成长型心智（Dweck）**："尚未"心态与成长型心智高度同源，但本 skill 把它绑在"自己跟自己比"的纵向比较框架里，且强调"第四种骄傲"——面对昨天的自己要骄傲，这不是纯谦虚，是双向姿态。

## I — 方法论骨架 (Interpretation)

本 skill 是"学习卡住后"的补救工具，含三个子工具，可单独用也可组合用。

在《反向学习》的五项修炼体系中，它对应**第一项修炼"反向学习"**——减法式学习，卸载坏习惯再安装新习惯。口诀是"**我要改变什么？**"《反向学习》系统列出了四个妨碍学习的坏习惯及其修炼替代：标准答案思维方式→参考答案思维方式；发散式学习（弥补短板、全面发展）→聚焦；碎片化学习→模式化学习；学用脱节（学而不用/学而乱用）→深层迁移。本 skill 的三个子工具就是帮你执行反向学习的诊断流程。

1. **三环学习模型**（借阿吉里斯双环学习扩展）——行动时带着三层假设：这个行动能实现目标（单环）/这个目标值得追求（双环）/我追求目标的底层心智模式合理（三环）。反思时分别检视三层，由外向内越来越难，**心智模式的改变最难也最重要**。多数人卡在单环（换行动），不愿改目标，更不愿动心智模式。
2. **负面情绪是学习信号**（处方性主张，非描述性研究）——进化论依据：肉体痛苦感是生存必需（无疼痛感的人会把自己打坏），情绪痛苦同理=需要改变的信号。三步：①捕捉具体情绪明确方向（焦虑/无聊/沮丧指向不同层面）②正面化（"我不是焦虑，我是在用心思考如何避免出错"）③三环反思。注意：这是"应然"处方——不管大多数人被负面情绪击倒，我们应这样给自己开方。
3. **学习导向诊断**（七种/八种）——原模型（英国大学生）：学术(内/外)+职业(内/外)+个人(内/外)+社交共七种；作者改造为职场八种：求知(内/外)+工作(内/外)+自我(内/外)+关系(内/外)。**是分析模式非描述模式**——一人往往混合多种导向。不同导向指向不同学习策略，可诊断反面镜：博物馆式学习（多为工作外导向，学得广不深）、贪官式学习（学了为教不为自己用）、天文学家式学习（学术外+自我外导向，谈资而非工具）。

配套：**老师解决两种困惑**（第104课）——表达出来的困惑（学生直接说出口）vs表现出来的困惑（学生不自知但行为暴露），可迁移为自我诊断："我表现出来的、自己却没意识到的困惑是什么？"

## A1 — 书中的应用 (Past Application)

### 案例 1: X 同学"空谈实际"——三环反思的缺席（第115、116课）

- **问题**: X 同学详细分享了一次失败的销售案例，希望大家探讨为什么失败。他一直在讲故事、讲琐碎行动，但讨论半天没有成果。
- **方法论的使用**: 作者用"三环学习模型"诊断——X 同学针对案例讲了很多琐碎的**行动**，但缺乏对**目标**和**心智模式**的提炼。即卡在单环（复盘行动），没走到双环（这个销售目标本身值不值得追求）和三环（我对销售/客户的底层心智模式是不是出了问题）。同时指出他缺元认知："我当时是怎么想的？"——没有把背后朴素的理论提炼出来。
- **结论**: 失败案例若只讲行动不讲目标和心智模式，就不是"从失败中学习"，只是"关于失败的困惑"——正如"干"不等于"干中学"。
- **结果**: 作者借此区分"空谈理论"（E 同学）和"空谈实际"（X 同学）两种反面，并提出"联系实际"必须有双方——实际和理论，缺一不可。

### 案例 2: C 同学"提不出好问题"——学习导向诊断（第111-112课）

- **问题**: C 同学的困惑是"自己为什么提不出好问题"。他自己总结了三点原因：懒得思考、没有复盘习惯、没有提问框架。归因于"懒"。
- **方法论的使用**: 作者用"学习导向"诊断——C 同学是培训师，他学绝大多数内容想的是"怎么讲给别人听"而非"我怎么用"，属于**工作导向（外在动机型）**，本质是博物馆式学习+贪官式学习。这解释了三点表面原因：①之所以直接给答案而非提问，是因为他从"博物馆"搬出藏品当答案，像讲解员而非提问者；②没有复盘习惯是因为博物馆里只有展品没有可反思的"看家模式"；③有提问框架但没真用，因为框架也是展品。
- **结论**: 归因于"懒"使方案表面化且缺乏操作性；归因于"学习导向"则指向可改变的结构——从外在动机转向内在动机，从"学了为教"转向"学了为用"。
- **结果**: 作者给出非常具体的方子（因为 C 的困惑有体温），并借此示范"困惑有体温，答案才准确"。

### 案例 3: G 同学"至暗时刻"——负面情绪作为信号+聚焦三环（第117-118课）

- **问题**: G 同学遭遇降薪或失去职位（至暗时刻），情绪不好，困惑表达不清，大概是自己以前学习取得了职业成就，现在形势复杂有深深的无力感，该怎么学习。
- **方法论的使用**: 作者先用"负面情绪是学习信号"——情绪过于强烈时难以学习，先平复；平复后把至暗时刻作为信号："事情不太妙，我该怎么改？"然后用三环反思+聚焦三环：①也许什么都不用改（逆境与他无关，是运气）；②但他对逆境的反应说明心智模式可改——把逆境作为学习机会、把成功更多归因于运气（而非能力）；③未来学习聚焦"擅长×热爱×机会"三环交叉地带，而非泛泛地学。
- **结论**: 负面情绪是入口，三环反思是路径，聚焦三环是出口。G 同学以前可能享受行业红利却归因为自己能力强，所以受打击大——这是心智模式问题。
- **结果**: 作者同时指出 G 以前是运动员，本应在一次次失败中成长，但这次没把运动场经验迁移到职场——元认知调用不够，可用三环学习模型训练元认知。

### 案例 4: 作者诊断学员"表达 vs 表现"的困惑（第104课）

- **问题**: LJ 同学在讨论中说了两段话，作者看到他的问题所在，但这问题不容易看出来。
- **方法论的使用**: 作者用"老师解决两种困惑"框架——表达出来的困惑（学生直接说出口，如 W 同学问学习风格）vs 表现出来的困惑（学生不自知但行为暴露，如说自己在"举一反三"的同学）。解决后者老师冒更大风险，但价值也在这里。类比医生望闻问切：不只听病人说不舒服，还要自己判断。
- **结论**: 这个框架可迁移——管理者任务是解决两种困惑；自我学习时也可自问"我表现出来的、自己却没意识到的困惑是什么？"
- **结果**: 示范了诊断的双重视角，是本 skill "帮别人诊断"分支的源头。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 失败后/焦虑后/至暗时刻想反思，但不知道从哪里下手，反思流于琐碎行动的罗列。
2. 学不下去、学而无获、学了很多却用不起来，怀疑动机或方向出了问题。
3. 学了很多却"提不出好问题""讲什么都讲不深"，怀疑自己是不是博物馆式/贪官式学习者。
4. 想帮别人（学员、下属、孩子、客户）诊断为什么学不进去，但对方说不出问题。
5. 负面情绪（焦虑/无聊/沮丧/挫败）反复出现，想把情绪转化为学习信号。

### 语言信号 (用户的话里出现这些就应激活)

- "这次失败后我想反思，但不知道从哪反思" / "我该怎么从失败中学习"
- "我学不下去" / "学了用不起来" / "我为什么提不出好问题"
- "我是不是博物馆式学习" / "我是不是贪官式学习" / "我像天文学家"
- "这次焦虑/挫败告诉我什么" / "负面情绪怎么用"
- "我下属/学员为什么学不进去" / "他问题出在哪我自己看不出来"
- "reflect on failure" / "learning orientation" / "stuck after failure" / "why can't I learn"

### 与相邻 skill 的区分

- 与 `si-wen-xuexi-fa`（四问学习法）的区别：那个是**学习流程**（听→找→变→用），本 skill 是**学习卡住后的反思诊断**——当四问走不下去、或"用"的环节反复失败时，回到本 skill 反思卡在哪一环、为什么卡。
- 与 `xuexi-fangshi-dengji`（学习方式等级）的区别：那个诊断**学习层级**（被动→主动→建构→互动/实践→协作），本 skill 诊断**学习动机**（导向）和**反思失败**（三环）——前者回答"我在哪一层"，后者回答"我为什么学不下去、失败后改什么"。
- 与 `xuexi-tiwen`（学习要有体温）的区别：那个**检验学习是否真发生**（认知/情感/行为三维度），本 skill 在**没发生或失败后**反思原因——前者是体检，后者是问诊。

## E — 可执行步骤 (Execution)

skill 被激活后，按用户情境分三支引导。

🔴 **CHECKPOINT · 情绪优先分流**：先判断用户此刻是否处于强烈负面情绪中（说话断续、反复诉苦、无法聚焦）。若是——无论他最初想做哪支，都先走分支 A 的情绪平复逻辑，不进 B/C；第117课明示"负面情绪过于强烈时难以学习"。若情绪平稳，再确认他是 A（自己失败/情绪想反思）、B（学不下去想诊断动机）、C（想帮别人诊断）哪一种，一次只走一支。

### 分支 A：遇失败/负面情绪 → 三步反思法

1. **捕捉具体情绪**——问"你现在的负面情绪具体是哪一种？"焦虑/无聊/沮丧/挫败/羞耻指向不同层面。焦虑常指向行动层，无聊指向内容层，羞耻指向心智模式层。
   - 完成标准：能说出一种具体情绪名词，而非"心情不好"。
2. **正面化情绪**——引导把"我不是 X，我是在 Y"造句。如"我不是焦虑，我是在用心思考如何避免出错"。避免被情绪击倒或沉溺其中。
   - 完成标准：产出一个中性/积极的重述句，且用户认可这不是自欺。
   - 判停条件：若情绪仍过于强烈（用户说话断续、反复诉苦、无法聚焦），先停止反思，建议平复后再回来——第117课明示"负面情绪过于强烈时难以学习"。
3. **三环反思**——由外向内依次检视：
   - 行动（单环）：这个行动能否实现目标？要不要换行动？
   - 目标（双环）：这个目标本身值得追求吗？要不要换目标？
   - 心智模式（三环）：我追求这个目标的底层心智模式合理吗？（如"成功主要靠能力"vs"成功主要靠运气"）★ **重点**
   - 完成标准：每一环都给出一句明确的判断，且至少在三环层产出一个"以前没意识到"的发现。若三环都"没问题"，多半是反思没到位——回到第一环再深入。

### 分支 B：学不下去/学而无获 → 学习导向诊断

1. **诊断学习导向**——让用户列出最近学的 3-5 样东西，逐个问："学这个是为了什么？"对照八种导向（求知/工作/自我/关系 × 内/外）归类。
   - 完成标准：每样东西都有一种主导导向+一种次要导向的判断。
   - 判停条件：若用户对所有东西都说"就是想学，没为什么"，提示这本身是个信号——大概率是社交/自我外导向（为了谈资而非工具），回到第 2 步用反面镜逼出证据。
2. **对照反面镜**——用三面镜子检视：
   - 博物馆式：学的东西彼此无联系、无深度，只是为了"讲给别人听"或"显得懂得多"？
   - 贪官式：学了为教别人，自己不打算践行？
   - 天文学家式：只谈遥远例子（谷歌、刘备）或只谈书本，不联系自己的实际？
   - 完成标准：明确说出自己主要落入哪面镜子（可多选），并举一个具体证据。
   - 判停条件：若用户说"我哪面都不像"，提示这是回避诊断——找最近一次"学完但没用上"的具体例子，从那一次反推落入了哪面镜子。
3. **调整导向**——从外在转内在、从社交转求知、从"为教"转"为用"。具体动作：选一样"工作外导向"的内容，转为"工作内导向"——问"这个内容怎么帮我把现在的工作做得更好？我具体用到哪里？"
   - 完成标准：产出一个导向调整的具体承诺+一个近期可执行的动作。
   - 判停条件：若用户只做口头承诺（"以后我会注意用在自己身上"）却说不出具体用到哪，提示这仍是贪官式语言，回到第 1 步重选一样内容落地。

### 分支 C：帮别人诊断 → 区分两种困惑

🔴 **CHECKPOINT · 助人意图确认**：进分支 C 前先确认用户是真想帮对方（学员/下属/孩子）诊断，还是只是来吐槽"这个人怎么学不进去"。若是吐槽——本 skill 不接，建议回到分支 B 诊断用户自己。确认是助人意图后，再走两步困惑的区分。

1. **先听表达出来的困惑**——让对方说他自己的困惑。注意：若困惑过于宏大（"怎么提出好问题"）或过于琐碎（全是故事），都不算合格的困惑。
2. **再观察表现出来的困惑**——自问"他本人不觉得是问题、但行为暴露的问题是什么？"如：说自己在"举一反三"实则没真懂、问问题是为炫耀而非求知、教别人的东西自己不用。
3. **诊断后开方**——像医生治病，针对具体情况开方（王阳明"因病开方"）。不要给一般性答案——"困惑有体温，答案才准确"。
   - 完成标准：给出一个针对对方具体表现的具体判断+一个具体建议，而非通用模型。若对方是"装睡的学习者"（ce14，假装学习只为社交/炫耀），明示本 skill 无法叫醒——只能等"社会的毒打"或放弃。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **情绪太强烈时**：第117课明示"负面情绪过于强烈时难以学习"。先平复（运动、倾诉、睡眠），再回到三步反思。本 skill 不是危机干预工具。
- **纯技术问题**：代码 bug、设备故障、纯知识盲点，不需要三环反思——直接查文档、问专家。三环反思用于"反复出现同类失败"或"行动-目标-心智模式层的问题"，不是所有问题。
- **单纯记忆背诵受挫**：背不下单词、记不住公式，是方法/练习量问题，不是动机或心智模式问题。用 `si-wen-xuexi-fa` 或专门记忆法。
- **首次尝试某事失败**：第一次失败往往是信息不足或技能生疏，反思到"行动层"即可（换方法）。只有**同类失败反复出现**才需要走到目标层和心智模式层。

### 作者在书中警告的失败模式

- **ce01 博物馆式学习**：学了很多模型但彼此无联系、无深度，只为讲给别人听或显得懂得多。面对任何问题都能从"博物馆"搬出藏品当答案，但不深究、不真用。提不出好问题（像讲解员而非提问者）。本 skill 分支 B 的核心诊断对象。
- **ce02 贪官式学习**：学了只为教别人，自己不打算践行。教营销但不真用营销，教领导力但不学领导力。商学院院长、培训机构、老师都可能陷入。本 skill 用学习导向诊断（工作外导向）识别。
- **ce03 天文学家式学习**：只谈离自己很遥远的例子（谷歌、刘备）或只谈书本上说了什么，不联系自己的实际。讨论半天别人不知道他是做什么的。学术外+自我外导向的混合。本 skill 用"联系实际的三条路"作解药。
- **ce04 空谈实际**：只讲故事、讲失败案例、讲琐碎行动，但不提炼理论、不调用模式。把"举自己的例子"变成"沉浸在自己的故事里"。"联系实际"必须有双方——实际和理论，缺一不可。X 同学的案例即为典型。本 skill 分支 A 的三环反思专门处理——把行动层的琐碎复盘上升到目标和心智模式层。
- **ce14 装睡的学习者**：假装学习——问问题不是真想知道答案，而是为了炫耀或社交。只有"我知道我知道"，没有真正进入"我知道我不知道"。无法叫醒，只能等"社会的毒打"或老师用"大棒子"打。本 skill 分支 C 遇此类应明示无能为力。

### 作者的盲点 / 时代局限

- **"负面情绪是信号"是处方性主张，非普适真理**：作者明示这是"应然"处方（不管人们怎么做，我们应这样开方），不是描述性研究。但实际使用中，严重负面情绪（抑郁、创伤后应激）需要专业心理干预，强行"正面化"可能造成二次伤害——本 skill 不替代心理咨询。
- **三环学习模型借用阿吉里斯并本土化**：阿吉里斯原模型是双环（行动/心智模式），作者加"目标"成三环。作者自承在第118课对斯坦诺维奇反思心智的解释"很可能不符合他的原意，是同化学习而非顺应学习"——借用有扭曲，严谨场合需回原文献。
- **学习导向来自英国大学的研究样本**：原模型基于一所英国大学的大学生样本，作者改造为职场八种。样本窄、文化特定，对中国职场、自由职业者、蓝领、退休人群的适用性需用户自行验证。
- **案例样本窄**：作者案例来自一个微信群30位正式生+10余旁听生，多为企业管理者/创业者/1位博士生。X/C/G 三位同学的诊断案例都偏管理培训场景。

### 容易混淆的邻近方法论

- **ABC 认知行为疗法**（Albert Ellis）：类似处——都承认"情绪-认知-行为"联动，都强调改变认知来改变情绪。区别：ABC 关注"非理性信念"的认知扭曲纠正，是心理治疗工具；本 skill 的三环反思关注"行动-目标-心智模式"三层假设的检视，是学习反思工具。ABC 的"信念"≈本 skill 的"心智模式"，但 ABC 不强调"目标层"的反思。
- **成长型思维**（Carol Dweck）：类似处——都强调心智模式/信念的改变。区别：成长型思维是单一心智模式（能力可增长 vs 固定），本 skill 的心智模式层是开放的——可能是"成功靠能力还是运气""失败是坏事还是信号"等任何底层假设。成长型思维可视为本 skill 三环反思中"心智模式层"的一个特例。
- **PDCA/PDSA**（戴明环）：与三环学习模型形似，但 PDCA 是质量管理循环（plan-do-check/study-act），重在"行动-反馈-修正"（单环）；三环学习模型多出"目标层"和"心智模式层"的反思。作者指出四问学习法是 PDSA 中 P（plan）的形成过程，本 skill 是 PDSA 中 S（study）的深化——尤其走到双环和三环时。

# 发现模式（分析问题的核心步骤）


## 刘澜视角（作者思维透镜）

> **体系定位**：本 skill 是"五项修炼"第四项——模式化学习的方法落地（专家握模式，新手只有碎片）。
> **作者镜片**：模式化镜片——模式如磁铁，碎片如铁屑；"我知道"若是模式知识，就能吸住"我不知道"的碎片。
> **招牌比喻**：磁铁吸铁屑——零散经验是铁屑，背后的共性/本质才是磁铁。
> **边界提醒**：建"模式树"有门槛，对新手是慢思考的硬仗，别指望一次读懂就成专家。

## R — 原文 (Reading)

> "分析问题，不仅第一步不是探究原因，第二步也不是探究原因。第二步是发现模式……第二步要问这样的问题：你所说的问题背后的模式是什么？第二步实际上是在找原因。但不是直接找原因，而是在模式的指导下找原因。第二步也是在找答案，在模式的指导下找答案。发现模式，既是找原因，也是找答案。"
>
> — 刘澜，第19-22课

> "如何找出更好的参考答案呢？从三个方向找。第一个方向是从原文的逻辑中找……第二个方向是从脑子中已有的模式里找……第三个方向是从自己想要解决的问题中找。"
>
> — 刘澜，第95课

## I — 方法论骨架 (Interpretation)

"发现模式"是四问学习法第二步"找"的展开，也是分析问题四步（界定问题→**发现模式**→提出方案→执行方案）的核心。

关键洞察：**分析问题的第二步不是直接找原因，而是先发现模式。** 直接找原因容易陷入就事论事的碎片；先找到模式，再在模式指导下找原因和找答案，才能挖到可迁移的本质。发现模式同时承担两个功能——既是找原因（解释为什么会这样），也是找答案（指导该怎么做）。

模式藏在哪里？藏在碎片表面之下，要"找"不是"想"。"想"是任何念头都算，"找"要求有目标地翻开表面。从三个方向找：
1. **从原文/经验的逻辑中找**——把显性要点及要点之间的关系都纳入，别漏掉关系。
2. **从脑中已有模式中找**——不管原文讲了什么，问自己"关于这类事我知道哪些模式"，可用"向上归类"（如把"政治工作"归为"激励"）。
3. **从要解决的问题中找**——把"听到的"和"要用的"并列，问"如果它们是同一回事，共同模式是什么"。

三个方向互补，没有标准答案，但有更优的参考答案。判断找到的模式好不好，用两个标准：能否帮理解"一类"事物的本质？能否指导"一个"情境中的行动？

## A1 — 书中的应用 (Past Application)

### 案例 1: P 同学找"解放军政治工作"背后的模式
- **问题**: P 同学读到"政治工作是我军生命线，两个原则是思想教育和模范带头"，要找到可迁移的模式。
- **方法论的使用**: 他"找"到的是作者的领导力口诀"我来"。但作者指出这不够——"我来"忽略了原文两个原则中的一个，且没抓住"要点之间的关系"。
- **结论**: 改用"五教"模型（说教/身教/管教/请教/传教）更深：说教和身教正好对应原文两个原则，还能延伸出"另外三个教该不该有"的进一步思考。
- **结果**: 示范了"从原文逻辑找"（要把两个原则及其关系都纳入）和"从已有模式找"（五教模型比"我来"更结构化）的区别——后者更优。

### 案例 2: "摇尾巴"不是模式
- **问题**: 小狗写书总结"摇尾巴就能讨人喜欢"，马能照搬吗？人能照搬吗？
- **方法论的使用**: 作者追问"摇尾巴背后有没有本质模式？这个模式是没有尾巴可摇的我也能学的？"——这就是"从要解决的问题找模式"。
- **结论**: 直接照搬表面行为（摇尾巴）是照搬碎片；要找到背后模式（如"主动示好""建立情感联结"）才能跨物种迁移。
- **结果**: 海底捞的店长照搬摇尾巴会失败，因为没找到模式。这是"发现模式"的反面教材——照搬碎片。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 分析一个问题时，列了一堆原因却理不出头绪，找不到根本原因。
2. 看到别人的成功经验/做法，想学但直接照搬又怕不适合自己。
3. 读完一段内容，能复述但说不出"这背后的规律是什么"。
4. 同一个问题反复出现，想找到底层模式一劳永逸。
5. 想把一个领域的经验迁移到另一个领域，但不知道迁移什么。

### 语言信号 (用户的话里出现这些就应激活)

- "这背后的模式/规律/本质是什么"
- "为什么总是这样" / "根本原因是什么"
- "我照搬了XX的做法但没用"
- "这个经验能不能用到我这儿"
- "怎么迁移" / "有什么共性"
- "underlying pattern" / "what's the model" / "transferable"

### 与相邻 skill 的区分

- 与 `si-wen-xuexi-fa`（四问学习法）的区别：那个是"听→找→变→用"完整流程；本 skill 专门展开第二步"找"——当用户已经"听"到了内容、卡在"找不到模式"时，从主框架切换到本 skill 深化。
- 与 `moshi-jujiao-xuexi`（模式化与聚焦）的区别：那个解决"该积累哪些模式、学多少"（模式库建设）；本 skill 解决"此刻面对这个碎片，怎么挖出模式"（单次提取动作）。
- 与 `cankao-daan-siwei`（参考答案思维方式）的区别：那个是思维底座（不把任何答案当标准答案）；本 skill 是找模式的具体操作，产出的模式本身就是"参考答案"——二者是"产出什么"和"怎么看待产出"的关系。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应引导用户按以下步骤找模式：

1. **明确"要找什么"——先界定问题/碎片**
   - 让用户先说清：面对的是什么现象/经验/内容？要解决什么问题？
   - 完成标准：能一句话说清"我在找什么的背后模式"。
   - 🔴 检查点：用户说不清"在找什么的背后模式"之前，不进入方向展开。若用户连"听到了什么"都模糊，先回到 `si-wen-xuexi-fa` 第一步"听"补素材，不要硬找。

2. **从三个方向找模式**
   - 顺序：先方向一（原文逻辑）打底，确认要点及其关系；再方向二（已有模式）和方向三（要解决的问题）并行展开。若用户已有明确模式储备，可先从方向二切入。
   - **方向一·原文逻辑**：把显性要点及要点**之间的关系**都列出。问"这些要点之间是什么关系？配合？对立？递进？"——关系往往是模式所在。
   - **方向二·已有模式**：不管原文，问自己"关于这类事，我脑子里有哪些模式？"若无，用"向上归类"（把具体问题归到更大类别，如"政治工作"→"激励"）再找。
   - **方向三·要解决的问题**：把"听到的"和"要用的"并列，问"如果它们是同一回事，共同模式是什么？"
   - 完成标准：至少从一个方向找到一个候选模式，且能说清它比表面内容深在哪。
   - 判停条件：若三个方向都挖不出任何候选模式，停止硬找。改做"向上归类"练习或回 `moshi-jujiao-xuexi` 补垒基学习，不要产出假模式凑数。

3. **用好模式两标准检验**
   - 标准1（理解"一类"）：这个模式能帮理解一类事物的本质吗？还是只解释了这一个案例？
   - 标准2（指导"一个"）：这个模式能指导我在这个具体情境中的行动吗？还是太抽象用不上？
   - 完成标准：两个标准都基本满足。
   - 🔴 检查点：找到 1 个候选就停是不达标的。至少产出 2-3 个候选再选最优，并提醒"还有没有更优的参考答案"——找模式没有标准答案，但有更优解。

4. **产出参考答案**
   - 把找到的模式写成一个可表述的结构（一句话+几点要素），明确它是"参考答案"而非标准答案。
   - 完成标准：产出一个明确的模式表述，可交给 `si-wen-xuexi-fa` 的第三步"变"继续。
   - 判停条件：若用户把模式写成"要努力""要复盘"这类无法指导行动的空话，退回标准2重检，要求落到可操作的具体要素。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **问题已清楚只需执行**：已经知道模式也知道怎么做，只差动手——直接执行，不必再"找"。
- **纯事实核对**：查一个数据、确认一个信息，不需要找模式。
- **情绪问题**：用户在情绪中，需要共情而非分析模式。
- **垒基学习阶段（软边界）**：用户脑中模式储备太少（还没建立看家模式），强行"找"会变空想。但若用户已有明确的"找"意图（如"看什么都觉得是模式但说不清"），**可激活本 skill**——先用方向二（已有模式）做简单练习建立初始储备，同时提示需补垒基学习（见 `moshi-jujiao-xuexi`）。不要直接拒绝。
- **没有任何碎片可找**：用户连"听到了什么"都说不清，先回到四问学习法第一步"听"。

### 作者在书中警告的失败模式

- **照搬摇尾巴**（ce05）：直接照搬成功者表面做法，没找背后的模式。看到"那么做"成功就模仿"那么做"，忽略幸存者偏差和情境差异。马学狗摇尾巴会失败。
- **第二步"想"得太随意**（ce13）：把"找"退化成"想"，任何念头都算"想"，没翻开表面。P 同学找到"我来"就停下，没继续找更深的"五教"。
- **找到一个就停**：找模式没有标准答案但有更优解，找到一个参考答案就停下来，会错过更好的模式。
- **只找不"变"不"用"**：找到模式就以为完成了，不做情境调整和落地——那是四问学习法后两步的事。
- **从原文逻辑找时漏掉"关系"**：只列要点不列要点之间的关系，而关系往往是模式所在（如政治工作两个原则的"配合"本身就是模式）。

### 作者的盲点 / 时代局限

- 作者假设所有有效经验都能找到模式，但创造性突破、灵感、默会知识未必都能模式化——对艺术、直觉类内容应承认"可能没有可迁移模式"。
- 强行找模式可能把本无模式的偶然现象套上模式，产生虚假规律感——找到的模式要用"好模式两标准"和实际"用"来检验。
- "向上归类"技巧依赖用户已有的模式储备，对初学者可能无效——此时应先做垒基学习。

### 容易混淆的邻近方法论

- **第一性原理**：从基本事实向上推演，与本 skill"从原文逻辑找"有重叠，但第一性原理强调"回到不可再分的基本真理"，本 skill 强调"翻开表面找藏着的关系结构"。
- **5Why**：连续问"为什么"找根本原因，是"直接找原因"的代表——作者明确批评这种做法，主张先找模式再在模式指导下找原因。

# 互动学习 TALKS


## 刘澜视角（作者思维透镜）

> **体系定位**：本 skill 是"参考答案思维方式"六策略之一——互动学习的方法落地。
> **作者镜片**：参考答案镜片 + 守破离——互动不是求认同，是把对方当参考答案，用三问消化。
> **招牌三问**：对在哪 / 错在哪 / 更好的观点是什么？（守·破·离同时使用）
> **边界提醒**：互动不等于闲聊；没有"破"和"离"的互动只是互相确认偏见，退化成标准答案抱团。

## R — 原文 (Reading)

> "用TALK来概括讨论时要做的事情：T指告诉，A指询问，L指倾听，K指保持一个开放的心态。我现在觉得可以加上一个S：S指总结大家发表过的观点……S是最难的。"
> "讨论模式建立在这样一个假设之上：没有人完全掌握了真理。"
>
> — 刘澜，《学会如何学习》第17课、第44课

> "参考答案思维方式的六个主要策略：洞见分类、标准参考答案、**互动学习**、注重过程而非结果、发现隐含的假设、反过来想。"
> "学校教育不鼓励讨论，根本原因还是标准答案思维方式和容器装水式学习观。"
>
> — 刘澜，《反向学习：学习力的五项修炼》第二章（机械工业出版社，2025）

## I — 方法论骨架 (Interpretation)

互动学习是比建构学习更高级的学习方式（见 `xuexi-fangshi-dengji`），它通过与他人碰撞把局部真理汇聚成更接近真理的参考答案。本 skill 是该层的操作工具集：

1. **TALKS 讨论五要素**——Tell 告诉 / Ask 询问 / Listen 倾听 / Keep 保持开放心态 / Summarize 总结。S 最难，因为它包含前四件事——既要听、问、又要建构框架组织起来，是高阶学习力也是管理力。
2. **交流四模式**——聊天（情感联结）/交易（妥协达成一致）/辩论（战胜对方，假设"我是真理你是谬误"）/讨论（共享局部真理）。主张"多讨论，少辩论"。
3. **讨论型问题三自问**——有助于我的学习？有助于对方学习？不损害关系？前两个至少一个肯定才问；三个都肯定才是好问题。
4. **变质疑为请教（双向）**——被质疑时认同"我不知道"反问求教；想质疑时改用请教句式（"你具体打算怎么做？为什么是好主意？"）。
5. **请教两原则 + 公式**——不问对自己没用的；不问自己没钻研过的。公式：请教 = 我知道 + 我不知道（先说自己知道什么、试过什么）。
6. **给予式分享**——拿好东西分给大家（我学到什么 + 为什么觉得好 + 如何帮我把问题想清 + 如何让我更好行动 + 还有什么困惑），而非拿困惑索取建议。
7. **对待评价三点法**——发现"内容"中的积极因素 / 发现"行为"中的积极因素 / 询问后续"行动"。第三点是把"评价"变成"反馈"的关键——只有包含下一步行动建议的才是反馈。正负评价一视同仁。

## A1 — 书中的应用 (Past Application)

### 案例 1: D 同学在微信群讨论中做总结（第17课）

- **问题**: D 同学分享"运气"主题并引发大家讨论，但此前其他同学分享后没人做总结，讨论散场即结束。
- **方法论的使用**: D 同学主动做 S（Summarize）——倾听大家说了什么（L）、提炼要点、找出观点之间的异同和关系、用框架组织起来。她走完了完整的 TALKS 流程。
- **结论**: 作者点评这是"学习力上的一个亮点：通过总结来学习"。总结同时调动主动学习（听）、建构学习（提炼模式）、互动学习（汇总他人观点）、模式化学习（用自己的模式吸收碎片），是高阶学习力。
- **结果**: 作者据此提出 TALKS 模型，并指出 MBA 课堂"小组代表总结"常沦为"说自己一个人的观点"，反衬 S 之难、之稀缺。

### 案例 2: 作者本人把质疑改为请教（第48课）

- **问题**: 作者听到家人提出一个主意，随口说"这个主意行不通"——直接下判断，引起对方强烈反弹。
- **方法论的使用**: 作者立刻补救，改用变质疑为请教的方向二（想质疑时改用请教句式）——"那你给我讲讲，你具体打算怎么做？为什么这么做是个好主意？还有没有更好的方法？"
- **结论**: 直接质疑的假设是"我确定你错"，但实际上"我们不是那么确定"（参考答案思维方式）。改成请教，既不放弃思考，又把对立变成共同探讨。
- **结果**: 作者承认"如果可以重新来一次，我一定不直接说'行不通'"——示范了即使是方法论提出者也要不断提醒自己，把工具变成"新的本能"。

### 案例 3: 贪官式学习反例（ce02，第67课）

- **问题**: 贪官在台上做反腐报告前会"学习上级精神、学习反腐败理论和案例"，但讲完后并不打算践行——学了只为教别人。
- **方法论的使用（反面）**: 这是对"互动学习"工具的扭曲使用——分享/讲课完全脱离"用"的环节，违背 `si-wen-xuexi-fa` 的"用不起来是假学习"。TALKS 的 T（Tell）变成单向输出，A（Ask）变成考别人，S（Summarize）变成搬标准答案。
- **结论**: 互动学习工具本身不能防止"贪官式"扭曲——只要分享者不打算把所教的东西用在自己身上，再漂亮的 TALKS 都是表演。
- **结果**: 作者把它作为反面标签贯穿全书，提醒：教别人前先问"我自己用了吗"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 参与讨论/会议时，不知道自己该说什么、该做什么，或讨论变成"擦火花"。
2. 想提问但怕被当成"考别人"或"显得权力感太强"，怕伤关系。
3. 被质疑/负面评价，本能想反击或气急败坏，想转化成学习机会。
4. 想分享自己学到的东西，但担心变成炫耀或变成"拿困惑索取建议"。
5. 想请教别人但不知道怎么问才能得到有用的回答。
6. 想给他人反馈/批评但怕打击对方，不知道怎么开口（给反馈方向——本 skill 三点法是收反馈，给反馈建议配合 SBI 模型，见 E 分支 6）。

### 语言信号 (用户的话里出现这些就应激活)

- "讨论时我该说什么" / "会议里我老插不上话"
- "怎么提问不伤关系" / "怕问得像在考对方"
- "他质疑我，怎么回" / "被批评了很不爽"
- "想分享又怕显摆" / "怎么请教才不被敷衍"
- "how do I discuss without debating" / "how to ask without offending"
- "turning criticism into feedback" / "sharing without showing off"

### 与相邻 skill 的区分

- 与 `si-wen-xuexi-fa`（四问学习法）的区别：那个是**单次学习**的完整流程（听→找→变→用），本 skill 是**多人互动场景**的工具集——当学习发生在讨论、提问、请教、分享、反馈中时调用。
- 与 `xuexi-fangshi-dengji`（学习方式等级模型）的区别：那个是**诊断工具**——判断你的学习处于被动/主动/建构/互动/实践/协作哪一层；本 skill 提供**互动层**的具体操作话术和动作。
- 与 `cankao-daan-siwei`（参考答案思维方式）的区别：那个是**思维底座**——"没有标准答案只有参考答案"的元态度；本 skill 是这一底座在互动中的**具体话术**——变质疑为请教、讨论型问题三自问都是参考答案思维方式的操作化。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 先识别用户处于哪种互动场景，再按下面对应分支引导：

🔴 **CHECKPOINT · 场景分流确认**：激活后先让用户点明当前是 6 种场景中的哪一种——①讨论/会议 ②提问 ③被质疑/想质疑 ④分享 ⑤收到评价 ⑥给他人反馈。一次只走一个分支，不要同时套多个分支的话术（如既当讨论又当提问会语句打架）。若用户描述含糊（"就是和人聊得不顺"），用一句话追问"具体是上面哪种时刻让你卡住"，确认后再进对应分支。

### 分支 1：若在讨论/会议中 → 用 TALKS（尤其做 S 总结）

1. 让用户先问自己：刚才我做了 T/A/L/K 中的哪几件？缺哪件？
2. 重点引导做 S——"你能用一句话总结大家观点的分歧在哪？关系是什么？用一个什么框架把它们组织起来？"
3. **完成标准**：用户能给出一段不偏袒任何一方、结构清晰的总结，且其中包含至少一个比任何单一发言都更深的"模式"。
4. **判停条件**：若用户只能说"甲说了 A，乙说了 B"——这是罗列不是总结，回到第 2 步重新问"分歧/关系/框架"。

### 分支 2：若要提问 → 先用三自问筛选

1. 让用户在提问前自问：①是否有助于我的学习？②是否有助于对方学习？③是否不损害关系？
2. 前两个至少一个肯定才问；若两个都否定，要么闭嘴，要么换问法。
3. 第三个若否定，比较收益与成本再决定。
4. **完成标准**：用户能说出每个自问的答案，且最终问句是"讨论型问题"（传递"我不知道但我想知道"的态度），而非"辩论型问题"（传递"我知道但你不知道"的考问）。
4. **判停条件**：若用户承认是"考对方"或"暴露对方不知道"——回到第 1 步，问"你真不知道吗？如果不知道，能否改成请教句式？"

### 分支 3：若被质疑/想质疑 → 变质疑为请教

1. **被质疑方向**：让用户认同对方假设"我不知道"，反问"你可不可以具体讲讲你的看法/你觉得我该怎么改？"——把负面情境变学习机会。
2. **想质疑方向**：让用户把"这行不通/你不懂"改成"你具体打算怎么做？为什么这么做是好主意？还有没有更好的方法？"
3. **完成标准**：用户能用"请教公式"（我知道 + 我不知道）重构回应——先说自己已知/已试的部分，再说自己不知道的部分。
4. **判停条件**：若用户坚持"我就是要指出他错"——提示进入辩论模式（见 B 段 ce25），可能既伤关系又学不到东西；问"你确定你是对的吗？"（参考答案思维方式的元问题）。

### 分支 4：若要分享 → 给予式分享

1. 让用户按格式准备：我学到什么 + 为什么觉得好 + 如何帮我把问题想清 + 如何让我更好行动 + 还有什么困惑。
2. 检查是否变成"拿困惑索取建议"——若是，提示这是索取式不是给予式。
3. **完成标准**：分享中既有"我用了什么"（体温/行动），又有"我还困惑什么"（邀请讨论），且考虑了听众的"我知道"水平。
4. **判停条件**：若用户只能讲"我读了什么"但讲不出"我怎么用"——提示可能陷入贪官式学习（ce02），先回到 `si-wen-xuexi-fa` 走完四步。

### 分支 5：若收到评价 → 三点法变反馈

🔴 **CHECKPOINT · 情绪闸门**：进流程前先确认用户情绪状态。若用户仍在强烈情绪中（愤怒/委屈/羞耻），**先不做三点法**——此时系统二未上线，强行走流程只会变成防御或表演。先共情一句（"被这么评确实不好受"），等用户说"我能冷静想了"再进第 1 步。

1. 内容中的积极因素——"批评里哪个词其实是优点？"（如"坚持低水平"中"坚持"是优点）。
2. 行为中的积极因素——"对方肯冒得罪风险说真话，意味着什么？"
3. 询问后续行动——"你觉得我该怎么改？高水平是怎样的？"
4. **完成标准**：用户能把一句"伤人"的评价转成一个具体的、可执行的下一步行动建议；正负评价一视同仁（收到正面评价也问"我怎么可以做得更好"）。
5. **判停条件**：若用户仍在情绪中无法调用系统二——先让其情绪平复，再回到第 1 步；情绪强烈时不要强行走流程。

### 分支 6：若要给他人反馈 → 说明边界，建议 SBI

1. 先说明：本 skill 的三点法是**收反馈**的工具（发现积极因素/发现行为积极/询问后续行动）；给反馈是反方向，建议用 **SBI 模型**（Situation 情境 - Behavior 行为 - Impact 影响）。
2. 两者配合使用：给反馈用 SBI（描述具体情境下的行为及其影响），收反馈用三点法（从收到的评价里提取积极因素并询问改进）。
3. 若用户只想知道"怎么开口不伤人"，可直接给 SBI 句式模板："在 [情境] 中，你 [行为]，这让我/团队 [影响]，我希望 [后续行动]。"
4. **完成标准**：用户理解给/收反馈是两个方向，并能说出自己当前需要哪个工具。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **纯信息交流**：双方只为传递事实（"会议几点开始"），不需要 TALKS 或变质疑为请教。
- **紧急指令**：抢险救灾、手术中等需要立即执行的场合，提问/请教流程是负担。
- **情感倾诉**：对方在情绪中需要共情，变质疑为请教会显得冷漠。
- **单向输出场景**：写作、讲课本身已是输出，本 skill 的互动工具不直接适用（可参考 `si-wen-xuexi-fa` 第四步"用"的输出形式）。

### 作者在书中警告的失败模式

- **辩论模式（ce25，第44课）**：交流目的是战胜对方而非接近真理。语言信号："我是真理的代表，你是谬误的化身"；想"考"对方、暴露对方的不知道；把答案当标准答案。讨论变"心头一股无名火"。
- **问没钻研过的问题（ce11，第36/58/91课）**：刚听到一个概念就拿出来分享、问问题；问题肤浅抓不住要害；不先自己尝试找答案。作者评："你这不是在学习，你这是在假装学习。"
- **问别人"我该怎么办"（ce12，第56课）**：直接要答案而非要思考方式。即使得到准确答案，没掌握背后的模式也不会用。正确问法是"我该怎么思考"或"我该用哪些模式来思考"。
- **贪官式学习（ce02，第67课）**：学了只为教别人，自己不打算践行。TALKS 沦为表演工具，违背"用不起来是假学习"。
- **索取式分享**：拿困惑求建议当"分享"，把互动变成索取。作者强调"分享在很大程度上是给予"。

### 作者的盲点 / 时代局限

- **案例样本窄**：互动案例几乎全部来自"《学习之美》学习圈"微信群（30 位正式生 + 10 余旁听生，多为企业管理者/创业者），对师生关系、家庭关系、跨文化场景、强弱权力不对等场景的适用性需用户自行迁移。
- **对辩论的批评可能过绝对**：作者主张"多讨论少辩论"，但学术辩论、法庭辩论、政策听证中的对抗式论证也有真理检验价值（波普尔"证伪"传统、密尔《论自由》第四章）。把辩论简化为"战胜对方"忽略了制度化的辩论规则（如不得人身攻击、必须回应对方论证）也能逼近真理。
- **TALKS 的独创性边界**：作者明确说"我最近看到有人用 TALK 来概括讨论"——TALK 模型是借用的，作者只加了 S。但 S = 总结 = 高阶学习力这一主张，与教育心理学中"生成性总结（generative summarizing）"的研究一致，并非作者独创；用户使用时不必把 TALKS 当成作者原创范式。
- **"请教公式"的局限**：请教 = 我知道 + 我不知道，在权力不对等场景（如下属问上司、学生问大牛）中，"我知道"部分若说得太长可能显得挑战权威；需要根据对方身份调整比重。

### 容易混淆的邻近方法论

- **非暴力沟通（NVC，马歇尔·罗森伯格）**：四步（观察/感受/需要/请求）也处理人际互动，但重点是**情感联结与冲突调解**；本 skill 的 TALKS、讨论型问题聚焦**学习与认知碰撞**，目标是从对方那里学到东西而非解决情感冲突。收到强烈情绪评价时先用 NVC 平复，再用本 skill 转反馈。
- **苏格拉底式提问**：也强调"我问你"，但苏格拉底式常预设"我知道答案、通过提问让你发现自己无知"，仍带权力感；本 skill 的讨论型问题三自问专门防这种"考问"姿态，要求提问者承认"我不知道但我想知道"。
- **反馈三明治 / SBI 模型（Situation-Behavior-Impact）**：是**给反馈**的工具，本 skill 的三点法是**收反馈**的工具——方向相反。配合使用：给反馈用 SBI，收反馈用三点法。

# 模式化学习与聚焦学习


## 刘澜视角（作者思维透镜）

> **体系定位**：本 skill 是"五项修炼"第三/四项——聚焦（学得少而深）+ 模式化的交汇。
> **作者镜片**：聚焦少而深镜片——二八法则对抗"贪多求浅"的系统1默认；少数知识比其他知识重要得多。

## I — 方法论骨架 (Interpretation)

本 skill 解决"学什么、学多少、聚焦哪里"三个问题。在《反向学习》的五项修炼体系中，它对应**第三项修炼"聚焦"**（替代"发散式学习"的坏习惯）和**第四项修炼"模式化学习"**（替代"碎片化学习"的坏习惯）——聚焦决定方向，模式化决定深度，两者咬合：聚焦的专题要靠模式化才能建起看家模式；模式化学习需要聚焦专题否则变成散点。

核心是六条相互咬合的判断：

1. **学习 = 模式 + 碎片**：学习的本质是用自己已有的少数模式去吸收新碎片，或在碎片中发现新模式。《反向学习》用"磁铁/铁屑"比喻点透——**模式知识是磁铁，能吸住碎片；碎片知识是铁屑，再多也组织不起来**。评判一种学习是否有效的试金石是——你在囤碎片，还是在用模式吸收碎片？博物馆式学习只有碎片无模式，是假学习。

2. **看家模式与必备模式**：看家模式是自己最擅长、反复使用、可用来吸收其他模式的核心模式（像看家功夫），数量少但管用。必备模式是"10点钟的模式"——简单、通用、能解决多数问题但不追求精准（如系统思考三层次）。学习策略是：聚焦少数必备 + 精通一两门看家。

3. **垒基学习（从 0 到 1 建立模式）**：进入一个新领域时先慢速建立初始模式，叫垒基学习。它难、慢、往往需要死记硬背，但重要——"如果说学习是用海绵吸水，垒基学习就是打造那块海绵"。没有"一"可举，谈何举一反三。

4. **聚焦三环（擅长 × 热爱 × 机会）**：绝大部分学习活动应围绕擅长、热爱、机会三环交叉地带进行。单纯聚焦擅长可能在造马车时代学造马车；单纯聚焦机会缺热爱撑不过至暗时刻；热爱是内在的，机会是外在的，擅长是连接内外的。三环交叉的专题要小（如"B2B 销售的目标管理"而非"目标管理"）。

5. **大盗式学习为主，小偷式为辅**：大盗式是围绕自己聚焦的问题读许多本书，提炼自己的答案，形成自己的模式树；小偷式是觉得有用就偷，不管体系。**做小偷的前提是当大盗**——大盗已有模式树，小偷只是偷树叶补充；纯做小偷只能搜集一堆碎片，无法变成大树。"读一本本好书"是误区，"读好一本书"才对。

6. **利用为主，探索为辅**：组织学习易犯"利用过度，探索不足"，但个人学习相反——大多数人犯的是"利用不足"。利用不足分两种：①不学习的人（利用不足+探索不足）；②买 100+ 门课的"天文学家"（利用不足+探索过度）。顿悟更可能发生在利用的领域。

> **聚焦六策略**（来自《反向学习》第三章）：聚焦不变 / 聚焦实用 / 聚焦擅长 / 聚焦专题 / 聚焦作者 / 聚焦样本——这六条是本 skill 步骤 2"聚焦三环"和步骤 3"大盗式学习"的具体展开，分别对应"聚焦什么维度"。

## A1 — 书中的应用 (Past Application)

### 案例 1: 作者围绕"领导力"主题读 100+ 本书建立看家模式

- **问题**: 作者要建立自己在领导力上的看家模式，怎么读？
- **方法论的使用**: 大盗式学习——围绕"领导力"这个聚焦主题，慢速读前 5-10 本书（垒基学习，建立初始模式），然后围绕该主题认真读了不止 100 本书。读到第 11 本左右就开始快了，因为看家模式已建立，后续是用看家模式去吸收其他模式和碎片（小偷式补充）。
- **结论**: "围绕一个主题读 10 本书的过程，就是建立自己的看家模式的过程。如果建立起来了，读后面 90 本书就是用看家模式去吸收其他模式和碎片，阅读速度就快了。"
- **结果**: 作者现在读一本领导力的书，一般只要半小时到一小时——因为大多数内容已可被看家模式快速吸收，只剩一两点新东西值得"偷"。

### 案例 2: C 同学的博物馆式学习（反面诊断）

- **问题**: C 同学在群里分享过许多管理模型，看似学了很多，但提不出好问题，面对任何问题都能从自己的"博物馆"里搬出一个模型当答案。
- **方法论的使用**: 作者用"学习=模式+碎片"诊断——C 同学的学习是博物馆式学习，知识像博物馆展品，琳琅满目但彼此无联系。他学的内容太多，没有时间深究；想的是"怎么讲"而非"怎么用"，所以提不出好问题，像讲解员而非提问者。
- **结论**: C 同学缺的不是更多模型，而是少数能串联其他模式的看家模式。他需要先停下来，选一个专题，慢速垒基，建一棵模式树。
- **结果**: 作者借此案例提醒：学得多 ≠ 学得深；没有模式树的"博览"是低效的。

### 案例 3: K 同学研究"左宗棠"作为聚焦样本

- **问题**: K 同学想知道左宗棠的才干是否源于"纸上谈兵"，能否迁移到当今职场。
- **方法论的使用**: 作者建议用"聚焦一个样本"的学习方法——选一个具足够丰富性、蕴含相当数量重要模式的样本（如左宗棠），反复钻研。引叔本华："读完希罗多德就学完历史了，因为它已包括所有后来的历史所包括的东西"——样本不在于多，而在于是否把重要模式都呈现了出来。
- **结论**: 聚焦样本的目的不是浅层次学样本本身，而是发现样本背后的真正模式。需要读好几本左宗棠传记，甚至研究论文，而不是凭印象提一个"能不能"的问题。
- **结果**: 作者借此说明聚焦一个样本与"不学高手个人经验"不矛盾——前者是找模式，后者是照搬碎片。

### 案例 4: Y 同学读《漫画丰田生产方式》（反面）

- **问题**: Y 同学说自己读了《丰田生产方式》，但同学指出她读的是《漫画丰田生产方式》。
- **方法论的使用**: 作者用模式化学习标准判断——漫画和小视频一样，形式决定了它只能传递碎片，无法建构模式。真正的钻研需要围绕丰田生产方式读一些书（专家之作、论文），而非用漫画或"百度一下"替代。
- **结论**: 钻研方式过于轻松 = 没有真正钻研。模式化学习对媒介有要求——印刷文化才有助于模式化学习。
- **结果**: 作者借此提醒：媒介即讯息，用错媒介再勤奋也是假学习。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **面对一堆待学的东西不知道选哪个**：书单很长、课程很多、领域很广，需要判断该聚焦什么、不学什么。
2. **学了很多却建不起自己的体系**：感觉知识散乱、彼此无联系，怀疑自己在做博物馆式学习。
3. **想围绕一个主题深读，但不知道读到什么程度算够**：例如"我想研究销售/管理/教育孩子，该读多少书？怎么读？"
4. **同时学多门功夫/多个领域，效果都不好**：怀疑自己分散了精力。
5. **想找到自己的看家模式**：感觉没有一个能反复使用、吸收其他模式的核心工具。
6. **判断要不要换学习方向/换老师**：现在学的东西是否还在三环交叉地带？是否该换地图？

### 语言信号（用户的话里出现这些就应激活）

- "我该学什么" / "学多少才够" / "同时学几样合适"
- "学了很多但用不起来" / "感觉知识很散" / "建不起体系"
- "想围绕一个主题深读" / "想找到自己的看家模式" / "我的模式树是什么"
- "这本书值不值得读透" / "该不该换老师" / "要不要换方向"
- "what should I learn" / "how many books" / "pattern library" / "focus topic"
- "博物馆式学习" / "大盗式学习" / "聚焦三环" / "看家模式"

### 与相邻 skill 的区分

- 与 `si-wen-xuexi-fa`（四问学习法）的区别：那个是"听→找→变→用"四步整体流程，解决"学到的东西怎么走完四步"；本 skill 解决"该学什么、学多少、聚焦哪里"，是上游的选材决策。二者互补——本 skill 决定学什么，四问学习法决定怎么吸收。
- 与 `faxian-moshi`（发现模式）的区别：那个是单次找模式的具体动作（四问学习法第二步"找"的深化），解决"这次怎么找出背后的模式"；本 skill 是长期模式库建设——选什么领域、读多少本书、建什么看家模式，是战略性而非战术性的。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应引导用户按以下步骤走：

🔴 **CHECKPOINT · 需求分流确认**：激活后先确认用户此刻是"选材决策"（该学什么/学多少/聚焦哪里）还是"吸收流程"（某段内容怎么用起来）。若是后者，本 skill 不对口——切到 `si-wen-xuexi-fa` 走听→找→变→用；只是"想多看几本书"也别硬套聚焦三环。确认是选材需求后再进入第 1 步。

1. **盘点已有模式，识别看家模式**
   - 让用户列出自己反复使用、最擅长、能用来吸收其他知识的 1-3 个模式（如四问学习法、PDCA、某种业务模型）。
   - 完成标准：能说出每个看家模式"我用它吸收过哪些碎片"，且能区分"我知道这个模式"和"我用它吸收过碎片"——后者才是真看家。
   - 判停条件：若用户列不出任何看家模式，提示他可能还没完成垒基学习，应先在一个领域慢速读 5-10 本书建立初始模式，再谈聚焦。

2. **按聚焦三环选学习领域与专题**
   - 引导用户分别列出：我擅长什么（具体到 B2B 销售、文案写作，而非"沟通"）/ 我热爱什么（具体到金钱、自主感、育人之乐，而非"成功"）/ 机会在哪里（行业性/职能性/角色性）。找三环交叉的小专题（如"B2B 销售的目标管理"而非"目标管理"）。
   - 完成标准：产出一个具体到可操作、三环交叉的专题，且能说明为什么是三环交叉而非单环。
   - 判停条件：若专题太大（如"如何管理"）或脱离自己实际工作生活，回到三环重新选。

🔴 **CHECKPOINT · 垒基前置确认**：进入"大盗式学习"前，先确认用户是否已在第 1 步盘点出至少一个看家模式、或愿意先慢速垒基。若用户既无看家模式、又只想"快速读书偷碎片"（纯小偷式），提示他必须先做第 1 步的垒基——"做小偷的前提是当大盗"，否则只会攒一堆无法成树的树叶。确认后才进入第 3 步。

3. **围绕聚焦专题做大盗式学习**
   - 引导用户：①先慢速读 5-10 本书建立模式（垒基学习），②再围绕该专题读够 10-100 本书，③边读边输出（讲课/写作），建构自己的模式树。判断是否已建立看家模式的标准是——读第 11 本书时是否变快了。
   - 完成标准：选定一个聚焦专题 + 列出已读/待读的 5-10 本核心书 + 一次输出（讲一课/写一篇）。
   - 判停条件：若用户只想"快速读书"而不愿慢速垒基，提示他前 10 本必须慢，否则建不起看家模式。

4. **警惕博物馆式学习，定期自检**
   - 让用户自问：我学的东西彼此有联系吗？我学的是为了"用"还是为了"讲"？我面对任何问题是不是都能从博物馆搬出一个模型当答案？
   - 完成标准：能说出最近学的 3 个东西如何挂在同一棵模式树上，而不是孤立展品。
   - 判停条件：若用户只能罗列学过的模型而说不出它们的关系，提示已陷入博物馆式学习，停止学新东西，先整合已有的。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **单次内容的吸收流程**：用户面对一篇文章/一节课想"怎么用起来"，用 `si-wen-xuexi-fa`，不是本 skill。
- **单次找模式动作**：用户卡在"这个背后是什么模式"，用 `faxian-moshi`，不是本 skill。
- **纯信息查询**：用户只想知道某个事实，不需要选材决策。
- **没有"听"够就想"找"模式**：脑子里的模式储备太少（垒基学习没做），强行聚焦也会变成空想——此时应先去多读几本该领域的基础书。

### 作者在书中警告的失败模式

- **博物馆式学习（ce01）**：学了许多模型但彼此无联系、无深度，只为"讲给别人听"或"看起来懂得多"。面对任何问题都能从博物馆搬出一个模型当答案，但不深究、不真用。信号：学的内容彼此无联系、想的是"怎么讲"而非"怎么用"、提不出好问题。
- **同时学太多本领（ce09）**：没有建立看家模式前就分散精力，同时练少林和武当，买 100+ 门课。结果要么什么都没学到，要么学成浅层次谈论各种知识的"天文学家"。信号：没有看家模式、探索过度利用不足、买的课都没学完。
- **读一本本好书（ce10）**：追求读"好书"（评分高、高手推荐）的数量，却没有一本读透、读成看家模式。把"好书"当客观标准，忽略学习力第一公式（好书因人而异）。信号：追求读书数量、选书只看评分、没有一本书反复读。
- **单纯小偷式学习（ce27）**：到处偷碎片，没有自己的模式树。判断不出什么对自己真正有用，搜集的只是一堆树叶和小枝丫，没法变成大树。信号：到处找"有用"的碎片、学了很多但无法整合。
- **读讲课型老师而非专家（ce26）**：跟着"讲课型"老师学，学到的是浅知识（像记者/编辑讲给外行听），以为这就是领域精华。要成为专家必须读专家之作。信号：学到的知识不够深刻、没读过该领域专家之作、不知道领域顶尖思考是什么。
- **用漫画/百度"钻研"（ce21）**：用漫画替代原著、用百度替代钻研。媒介形式决定它只能传递碎片，无法建构模式。信号：钻研方式过于轻松、觉得"知道概念"就等于"掌握概念"。

### 作者的盲点 / 时代局限

- **强依赖前作**：本书是《反向学习》的实战篇，"模式""看家模式""模式树"等核心术语在前作已建立，独立读者可能不熟悉——使用本 skill 时若用户不熟悉这些词，先用日常语言解释。
- **案例样本窄**：约 50 个学员案例多为企业管理者/创业者/职场人，对学生、蓝领、自由职业者、退休人群的适用性未充分验证。三环（擅长×热爱×机会）对还在探索阶段的年轻人可能难以直接套用。
- **"模式"普适性假设**：作者假设所有有效学习都能归结为"找模式"，但创造性突破、灵感、默会知识的获得未必都能被模式化（如艺术、诗、直觉）。强行找模式可能把本无模式的偶然现象套上模式，产生虚假规律感。
- **"用"的优先性假设**：作者整体导向工具主义，把"用"置于"知"之上，可能贬低纯粹求知价值——对为知识而知识的场景（哲学思辨、审美、纯数学）应放宽"用"的标准。
- **个人权威色彩**：部分判断（"我就是这么认为的"）依赖作者个人权威而非论证，读者应保持参考答案思维方式。

### 容易混淆的邻近方法论

- **费曼学习法**：强调"教别人"来检验理解，相当于本 skill 中"通过输出学习"的一种形式（讲课），但不覆盖"学什么、学多少、聚焦哪里"的战略决策。
- **主题阅读法（Syntopical Reading，出自《如何阅读一本书》）**：与本 skill 的"大盗式学习"形似——都是围绕一个主题读多本书。区别在于：主题阅读法强调比较不同作者的观点得出自己的结论，本 skill 强调建构一棵自己的模式树，且强调"读好一本书"（建看家模式）优先于"读多本书"。
- **刻意练习**：强调在舒适区之外的高难度练习+反馈，是"怎么练"的方法论；本 skill 是"学什么"的方法论。二者可配合——选定聚焦专题后，用刻意练习的方式练看家模式。

## I — 方法论骨架 (Interpretation)

四问学习法是把任何"碎片"（书本、经验、他人观点、生活事件）转化为"自己能用得上的东西"的主轴流程。在《反向学习》的五项修炼体系中，它是**第五项修炼"深层迁移"的专属工具**——深层迁移要解决"学用脱节"（要么学而不用、要么学而乱用）这个坏习惯，把模式知识应用到新情境里；四问学习法就是执行这个迁移的四步流程。分四步：

1. **听**——我听到/看到什么？如实接收对方的显性内容，不急于评判。
2. **找**（作者把"想"修正为"找"）——这背后藏着什么模式？"想"太随意，任何念头都算"想"；"找"要求有目标地翻开表面，把藏着的结构挖出来。这是四步里最难、最关键的一步，有专门的深化 skill `faxian-moshi`。
3. **变**——这个模式怎么根据我的情境调整？模式不能生搬硬套，要"变"成适合我的版本。
4. **用**——我用到哪里？具体到下一步行动。"用"既是试金石（用不起来的学习是假学习），也是脚手架（思考怎么用，反而把知识学得更深）。

四步顺序不可变：没有"听"够就"找"是空想（思而不学则殆）；只"听"不"找"是把碎片当知识；"找"到模式不"变"是生搬硬套；不"用"则前三步全废。越往后越难、越要靠自己。

## A1 — 书中的应用 (Past Application)

### 案例 1: P 同学读"解放军为什么能赢"
- **问题**: P 同学读到"政治工作是我军的生命线"，两个原则是思想教育和模范带头，想用到自己的项目管理中。
- **方法论的使用**: 他按四问学习法写：听到（两个原则）→想到（作者的领导力口诀"我来"）→变成（企业运营既要思想教育又要表率）→用到（项目管理）。
- **结论**: 方向正确，但作者指出第二步"想"得太随意——"我来"不够模式化，没有挖到藏着的东西。若改用"五教"模型（说教/身教/管教/请教/传教）会更深。
- **结果**: 作者借此提出把"想"改为"找"，并衍生出"找模式的三个方向"（见 `faxian-moshi`）。

### 案例 2: 作者"变着花样"用四问学习法分析学员案例
- **问题**: 全书约 50 个学员案例，每个都要分析"学得对不对"。
- **方法论的使用**: 作者反复用四问学习法作为分析工具——学员"听"到了什么、"找"到什么模式、"变"得是否切己、"用"得是否具体。
- **结论**: 四问学习法不仅是学习工具，也是诊断工具：哪一步出问题，学习就在哪一步失效。
- **结果**: 示范了同一个工具在不同情境下的灵活使用，是"看家模式"的范例。

### 用户会在什么情境下需要这个 skill?

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应引导用户按以下步骤走：

🔴 **CHECKPOINT · 起点确认**：激活后先确认用户手上的"碎片"是什么形态——一本书/一节课/一个经验/一条金句/一条新闻？并确认它已"听"到什么程度（读完了？只听了片段？）。若用户还没"听"够（只读了一句话、只听了个标题），先提示去多"听"再回来，不要直接跳到第二步"找"——否则会变成"思而不学"（ce18）。确认后进入第 1 步。

1. **听——如实接收**
   - 让用户用一两句话复述"听到/看到"的显性内容（对方说了什么、书里写了什么）。
   - 完成标准：能区分"对方明确说的"和"我自己加的判断"。
   - 判停条件：若用户复述时夹带大量自己的推断、分不清"对方说的"和"自己加的"，提示这是"学而不思"的反面——听成了自己的预设，回到 🔴 起点确认，请其只说对方原话。

2. **找——挖背后的模式** ★ 最关键
   - 引导用户问："这背后藏着的模式是什么？"强调是"找"不是"想"——要翻开表面，不是随便冒念头。
   - 可调用 `faxian-moshi` skill 的三个方向（原文逻辑/已有模式/要解决的问题）辅助。
   - 完成标准：找到至少一个比表面内容更深的"结构"，且能说出它为什么是模式而非碎片。
   - 判停条件：若用户只能复述表面内容、找不到任何深层结构，提示这可能是"思而不学"或内容本身无模式，回到第一步多"听"几个来源。

3. **变——根据情境调整**
   - 问："这个模式怎么根据你的情境变形成你能用的版本？"提示不要生搬硬套。
   - 完成标准：产出一个针对用户具体情境的、调整过的模式版本，而非原文照搬。
   - 判停条件：若用户只是把原文模式换了个主语复述（"我要用五教模型"但没说怎么结合自己的具体情境），提示这是生搬硬套（不"变"），回到第二步检查找到的是不是太浅——可能只挖到了表面，需要调用 `faxian-moshi` 再深挖一层。

4. **用——落到下一步行动**
   - 问："你具体用到哪里？下一步做什么？"要求具体到可执行的动作，不接受"我会注意"这类模糊承诺。
   - 完成标准：有一个明确的、近期可执行的行动；能说清"用了之后怎么检验是否有效"。
   - 判停条件：若用户说不出具体行动，往往说明前三步没走完，回到第二步重新"找"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **纯信息查询**：用户只是想知道某个事实（"这本书作者是谁"），不需要四步流程。
- **单纯记忆背诵**：背单词、记公式等机械记忆任务，四问学习法是负担。
- **情绪倾诉/安慰**：用户在情绪中，需要的是共情而非流程化分析。
- **没有"听"够就想"找"**：用户脑子里的模式储备太少（垒基学习没做），强行"找"会变成空想——此时应先去多"听"（读书、跟老师），见 `moshi-jujiao-xuexi` 的垒基学习。

### 作者在书中警告的失败模式

- **思而不学则殆**（ce18）：没"听"够就"找"，思没有学的根基，思也不深刻。四步顺序不能变。
- **第二步"想"得太随意**（ce13）：把"想"当自由联想，任何念头都算"想"。作者因此把"想"改为"找"——"找"要求有目标、翻开表面。
- **用得太宽泛**：第四步"用"如果只说"用到工作中"而拿不出具体动作，等于没用。P 同学的"用到项目管理"就是用得太宽泛。
- **学而不思**（与思而不学相反）：只"听"不"找"，把碎片当知识，停留在被动学习。
- **不做习题**（ce28）：读书但不做习题=没有"想"和"用"的环节，是假学习。

### 作者的盲点 / 时代局限

- 作者强依赖前作《反向学习》的概念体系，独立读者可能不熟悉"模式""看家模式"等术语——使用本 skill 时若用户不熟悉这些词，先用日常语言解释。
- "用不起来的学习一定是假学习"把"用"置于"知"之上，可能贬低纯粹求知价值——对为知识而知识的场景（如哲学思辨、审美）应放宽"用"的标准。
- 案例多为企业管理者/创业者，对学生、蓝领的适用性需用户自行迁移。

### 容易混淆的邻近方法论

- **PDCA/PDSA**（戴明环）：与本 skill 的"听想变用"形似，但 PDCA 是质量管理循环，本 skill 是学习循环；作者指出四问学习法其实就是 PDSA 中 P（plan）的形成过程。
- **费曼学习法**：强调"教别人"来检验理解，相当于本 skill 的"用"的一种形式，但不覆盖完整四步。

# 学习方式等级模型（被动→主动→建构→{互动,实践}→协作）


## 刘澜视角（作者思维透镜）

> **体系定位**：本 skill 是刘澜"学习方式等级"模型（被动→主动→建构→互动）的方法落地。
> **作者镜片**：已知-未知依存镜片——学习 = 我知道 + 我不知道；你已知道什么，决定能吸收什么"我不知道"。
> **招牌表达**：没有放之四海皆准的好书——选书/听课先看自己的"我知道"能否撞出"我不知道"。
> **边界提醒**：等级不是鄙视链；被动学习也有其场景，关键是不长期停留在单一层级。

## R — 原文 (Reading)

> "一个比较完整的学习方式等级模型（按照有效程度从低到高）是这样的：最底层是被动学习，往上是主动学习，再往上是建构学习，再往上则左右分叉，并列为互动学习（讨论式学习）和实践式学习，再往上则左右合流为协作式学习。"
>
> — 刘澜，第107课

---

## I — 方法论骨架 (Interpretation)

学习方式有等级，越高级越有效，也越难。从低到高五级：**被动→主动→建构→{互动, 实践}→协作**。后者包含前者，并调动更多认知手段——这正是它更有效的原因，也正是它更难的原因。

- **被动学习**：只接收，如听课、听书、看小视频。
- **主动学习**：用自己的话复述、提问、提炼要点。
- **建构学习**：用自己的语言和角度重组，把单点连成网络。
- **互动学习**：与他人讨论（TALKS）；**实践式学习**：干中学，带假设+反馈+修正。两者都比建构高级，但路径不同。
- **协作式学习**：一群人合作做一个项目，=互动+实践。最难，潜力满分 200，但很可能只得 80。

作者对季清华 ICAP（被动/主动/建构/互动）的升级是补入**实践式学习**和**协作式学习**——前者针对学校教育不研究"干中学"的盲区，后者点破"行动学习项目难做"的根源：它是最高级学习方式，参与者往往连基本层级都没掌握。

配四种"我知道"元认知诊断学习准备度：①我知道我知道；②我知道我不知道（第一种，来自对知识的思考，更高级）；③我知道我不知道（第二种，来自对实践的思考）；④我不知道我不知道（盲区）。学习路径：第二种"不知道"→"知道"→第一种"不知道"（更高级困惑）。"运用自如"往往卡在低层"我知道我知道"，未进入"我不知道"。

## A1 — 书中的应用 (Past Application)

### 案例 1: 作者用等级模型诊断"听书是低效学习"
- **问题**: W 同学把听十来分钟音频解读当作读书的替代，自以为高效。
- **方法论的使用**: 作者用季清华模型诊断——听书"主要是被动学习，想要加上一些主动学习，是可以的，但能加上的有限"。读书可停下来想、画线、写批注（建构）、甚至联系作者（互动），听书时很难做到。
- **结论**: 学习方式的有效性由它调动的认知手段多少决定。听书的天花板就是被动学习+少量主动学习，而读书可上探到建构甚至互动。
- **结果**: 处方——听书可作为补充，但不能作为主要学习手段；想真正吸收一本书，必须回到读书。

### 案例 2: JK 同学"互动积极但实践难"
- **问题**: JK 同学在群里讨论所学知识（互动学习）比较积极，但难以把所学付诸实践。
- **方法论的使用**: 作者用升级版等级模型诊断——互动学习已是较高级别，但实践式学习更难，"很可能它比互动学习更加有效一些，因此也更加难一些"。
- **结论**: 从互动到实践不是自然发生，而是再上一个台阶。互动学习积极≠实践能力强。
- **结果**: 处方是带着四问学习法明确假设去干中学（实践式学习=验证并修正行动/目标/心智模式三层假设），让"干"变成"干中学"。

### 案例 3: S 同学"运用自如"实为低层"我知道我知道"
- **问题**: S 同学说自己对数个管理模型"了然于胸、运用自如"，特别提到管理者三大能力模型。
- **方法论的使用**: 作者用四种"我知道"诊断——S 同学处在低层次的"我知道我知道"，而作者自己因掌握更深才产生她没有的"我知道我不知道"。"她对这些模型的'我知道'还在知识的圆圈之内，而我的'我知道'可能更接近圆圈的边界。"
- **结论**: "运用自如"是相对以前的自己而言，面对未来的自己应保持第四种谦虚。掌握得越浅，越容易觉得掌握；掌握得越深，越能发现自己的"不知道"。
- **结果**: 处方——保持愚蠢才能保持饥饿，从"我知道我知道"跨越到"我知道我不知道"才是真升级。

### 案例 4: 行动学习项目为何难做
- **问题**: 企业培训中的"行动学习"项目（一群人合作解决一个实际工作问题）普遍推不动、效果差。
- **方法论的使用**: 作者用等级模型诊断——行动学习就是协作式学习，是最高级学习方式，"包括了所有的学习方式。而那些参与者很可能连比较基本的学习方式都没有掌握好"。
- **结论**: 协作式学习潜力满分 200，但参与者层级不够，实际只得 80。越有效的学习方式越难，倒过来说也成立。
- **结果**: 处方——别直接上协作式学习，先评估参与者是否已掌握被动/主动/建构/互动各层级，逐级升级。

### 用户会在什么情境下需要这个 skill?

1. 学了很多（听课/读书/听书/看视频）却感觉没进步，想诊断自己的学习卡在哪一层。

5. 纠结该选哪种学习方式（听书 vs 读书、看视频 vs 读原著、自学 vs 讨论 vs 干中学）。

### 与相邻 skill 的区分

- 与 `si-wen-xuexi-fa`（四问学习法）的区别：那个是**单次学习流程**（听→找→变→用），本 skill 是**学习方式的层级诊断**（被动→主动→建构→{互动,实践}→协作）。四问学习法可在任一层级使用，但不同层级效果不同——本 skill 诊断你在哪层。
- 与 `xuexi-tiwen`（学习要有体温）的区别：那个检验**学习是否真发生**（认知/情感/行为三维度），本 skill 诊断**学习在哪个层级**。体温是"有没有动起来"，层级是"动到哪一级"。
- 与 `hudong-xuexi-talks`（互动学习 TALKS）的区别：那个专门展开互动学习的操作工具，本 skill 把互动学习定位在等级模型中——当你想从建构升级到互动时，先来本 skill 定位，再去 TALKS 取工具。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应引导用户按以下步骤走：

1. **诊断当前学习在哪个层级** ★ 最关键
   - 让用户描述一次具体的学习活动（如"我听了一节 20 分钟的课"），对照五级模型判断：被动（只听）/主动（复述提问）/建构（用自己的话重组）/互动（与人讨论）/实践（干中学带假设）/协作（一起做项目）。
   - 同时用四种"我知道"诊断准备度：是"我知道我知道"（舒适区）、第二种"我不知道"（实践困惑）、"我知道"（已掌握）、还是第一种"我不知道"（高级困惑）？
   - 完成标准：能说出"我的学习在 X 层级，我的'我知道'状态是 Y"。
   - 🔴 检查点：若用户描述的学习活动无法归入任一层级（既不像被动也不像主动），先别急着定级——回到"具体描述一次学习活动"重做，不要硬套层级。若用户把听书说成"学习"，明确点出它主要是被动学习，天花板有限，不能替代读书。

2. **识别可升级的下一级**
   - 问："下一级是什么？为什么你现在升不上去？"
   - 完成标准：找到一个具体的、相邻的升级目标，而非跨越多级（如不要从被动直接跳到协作）。
   - 判停条件：若用户想从被动直接跳到协作（跨多级），拦住——要求先定一个相邻升级目标（如被动→主动），逐级爬升。协作是最高级学习方式，没掌握低层直接上协作必失败（见案例4）。

3. **用对应手段升级**
   - 被动→主动：复述要点、提三个问题、画线写批注。
   - 主动→建构：用自己的话重组；把单点连成网络；事前建模（听讲前先建构自己的模型）。
   - 建构→互动：找人讨论，调用 `hudong-xuexi-talks` 的 TALKS 模型。
   - 建构→实践：带假设去干中学，用三环学习模型（行动/目标/心智模式）反思。
   - 互动+实践→协作：一群人合作做一个真实项目。
   - 完成标准：产出一个针对当前层级的、具体的升级动作。
   - 判停条件：若用户列出的升级动作仍停留在当前层级（如"我要多听几遍"来从被动升级——听再多也是被动），指出这是原地打转，回到对应手段重新选一个真能调动更多认知的动作。

4. **警惕虚假升级**
   - 自问："我是不是在'运用自如'的舒适区？"——掌握得越浅越容易觉得掌握。
   - 自问："我是不是只调动了一种认知手段？"——VARK 把自己"定型"就是自我设限。
   - 完成标准：能说出一个自己尚"不知道"的具体点（从"我知道我知道"进入"我知道我不知道"）。
   - 🔴 检查点：若用户说不出"不知道"的点，判定还在低层"我知道我知道"的舒适区——回到第1步重新诊断，不从"虚假升级"直接进入协作处方。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **纯信息查询**：用户只想知道某个事实（"ICAP 是谁提出的"），不需要层级诊断。
- **单纯记忆背诵**：背单词、记公式等机械记忆任务，等级模型是负担。
- **情绪倾诉/安慰**：用户在情绪中，需要的是共情而非层级分析。
- **单次学习流程的执行**：用户想完成一次"听→找→变→用"，用 `si-wen-xuexi-fa`，不要混入层级诊断。
- **学习是否真发生的检验**：用户想判断学习有没有真发生，用 `xuexi-tiwen` 的三维度体温模型。

### 作者在书中警告的失败模式

- **小视频学习**（ce06）：媒介即讯息——小视频的形式（几分钟、娱乐化、注意力分散）决定它只能传递数据和信息，不能传递模式化知识。是典型的被动学习且无法升级。
- **听书是低效学习**（ce07）：听书"主要是被动学习，想要加上一些主动学习，是可以的，但能加上的有限"。听书时无法停下来想、画线、写批注、联系前后内容。
- **装睡的学习者**（ce14）：只有"我知道我知道"，没有真正进入"我知道我不知道"。问问题是为了炫耀或社交，不是为了学习。无法叫醒，只能等"社会的毒打"。
- **"运用自如"的虚假掌握**（ce15）：S 同学自以为运用自如，实际是低层次"我知道我知道"。掌握得越浅越觉得掌握，掌握得越深越发现"不知道"。
- **VARK 把自己"定型"**（ce22）：说自己是"听觉型"所以只听书不读书。VARK 只关注学习的"听"这一步，且把自己看作名词/形容词而非动词。重要的是"做什么"而非"是什么"。
- **不做习题**（ce28）：读书但不做习题=没有"想"和"用"的环节=假学习。做习题是主动学习、建构学习和互动学习（与出题者互动）的过程。

### 作者的盲点 / 时代局限

- **借用季清华框架的本土化整合**：作者自承在第118课对斯坦诺维奇反思心智的解释"很可能是不符合他的原意的。在这一点上，我是在同化学习，而非顺应学习"——对 ICAP 的升级也带有同化色彩，用户使用时若需严格学术语境应回到原始文献。
- **对学校教育的简化批评**：作者将 ICAP 未纳入实践式学习归因于"其提出者主要研究学校教育"——这忽视了学校在系统知识结构、社会化、批判思维训练上的价值，对学校教育的批评偏简化。
- **协作学习"有效"是潜力非保证**：作者明确"这里的有效，说的是潜力"——协作式学习满分 200 但可能只得 80。用户不要把"高级"等同于"必然有效"，低层级学好可能比高层级没学好更有效。
- **案例样本窄**：等级模型的多处案例（JK/S/行动学习）来自企业管理者微信群，对学生、蓝领、自由职业者的适用性需用户自行迁移。

### 容易混淆的邻近方法论

- **布鲁姆认知层级**（记忆/理解/应用/分析/评价/创造）：描述**认知目标**的深度层次，本 skill 描述**学习方式**的层级。前者是"学到什么程度"，后者是"用什么方式学"。
- **DIKW 模型**（数据/信息/知识/智慧）：描述**信息**的层次，本 skill 描述**学习方式**的层级。前者是"学到的内容是什么"，后者是"学习的动作是什么"。

# 学习要有体温（认知/情感/行为三维度动起来）


## 刘澜视角（作者思维透镜）

> **体系定位**：本 skill 是判断"学习是否真发生"的体温检测工具。
> **作者镜片**：动词化/用镜片——体温是学习发生的信号；用不起来 = 没体温 = 假学习。
> **招牌提问**：学到这刻，我"变"了什么、"用"了什么？答不出就是没体温。
> **边界提醒**：刘澜自己承认"体温"概念在写作中不断变化、尚未定型——把它当活的检查清单，别当死标准。

## R — 原文 (Reading)

> "学习有三种体温，分别来自认知、情感和行为。学习就是新旧认知、新旧情感、新旧行为的纠缠互动，新知识由此而产生。"
> "体会就是用身体去互动……切己，就是用别人的知识（切），联系自己的实际（己）。"
>
> —— 刘澜，第73课、第89课

---

## I — 方法论骨架 (Interpretation)

学习要有体温 = 认知 / 情感 / 行为（3H：Head / Heart / Hands）三维度都要动起来，新旧之间纠缠互动才产生新知识。没有体温 = 没有真正学习发生。

**体温概念的演化**（作者明确呈现思考过程，是"注重过程而非结果"的示范）：
- v1（第24课）：两种带着体温学习的方式 —— 用身体辅助学习（听想变阶段调动身体，如站到桌子上换视角）+ 用身体落实学习（"用"阶段真正行动起来）；
- v2（第72课）：两种体温 —— 思考的体温（学到的知识跟已有知识怎么联系）+ 行动的体温（学到的知识跟行动怎么联系）；
- v3（第73-75课）：三种体温 —— 认知 / 情感 / 行为，对应 3H 模型。

**两个操作工具**（拆解汉字得来，第89-90课）：
- **切己 = 己 + 切**。"己"是举自己的例子、谈自己的实际问题；"切"是在别人的知识与自己的问题之间建立认知/情感/行为三个维度的联系。
- **体会 = 体 + 会**。"体"是身体/自己，"会"是会合、互动；体会就是用身体去互动，从认知/情感/行为三维度互动。
- 两个词"其实很像，意思差不多"——体对应己，会对应切。作者翻来覆去变着花样讲，是因为重要的事情要说三遍、说十遍。

**知识的三层境界**（第108课，借禅宗三境界）：
- 第一层：看山是山 —— 具体情境中的经验知识（碎片，看黄山是黄山）；
- 第二层：看山不是山 —— 脱离情境的抽象模式（看黄山不是黄山，是"山"）；
- 第三层：看山仍是山 —— 抽象模式与具体情境的结合（同时看到"山"和黄山），是最高级的知识，对应四问学习法中的"用"。

**困惑要有体温**（第108课）：困惑必须是自己的、来自实际问题，答案才准确；替黄山困惑得不到真成长。

## A1 — 书中的应用 (Past Application)

### 案例 1: F 同学分享要事管理"没体温"（第89课）
- **问题**: F 同学分享作者关于要事管理的主要观点，以及他在工作中的应用。作者点评：仍然存在"体温"问题——"我看到的只有对我的知识以及他的做法的介绍"。
- **方法论的使用**: 作者用"体会=体+会"框架从三维度诊断——认知上（新旧认知如何融合？）、情感上（认知融合带来的情感变化？比如对"正确的人"的认知是否引起对某个员工的情感变化？）、行为上（应有的行为与现有行为有何不同？情感在多大程度上阻碍了行为转变？）。
- **结论**: F 同学只介绍了知识和做法，三个维度的互动都没讲。体温不足 = 真正的学习没发生。
- **结果**: 作者借此提出"体会就是用身体去互动"，从认知/情感/行为三维度互动——"真正的学习，的确很难。你需要在认知、情感和行为三个维度上动起来。"

### 案例 2: X 同学切己在"己"上好，在"切"上不够（第90课）
- **问题**: X 同学分享读到的一段话如何加深了他对"制定人生愿景的三环模型"的理解。作者之前肯定过他经常举自己的例子。
- **方法论的使用**: 作者用"切己=己+切"框架诊断——X 同学在"己"（举自己的例子）上做得好，但在"切"（在别人知识与自己问题间建立认知/情感/行为联系）上不够。
- **结论**: 若要求再高一些，他应该讲：自己以前对三环模型的认知是什么、存在的困惑是什么、读到的这段话是怎么解开这个困惑的。只举例子不等于切己，还要建立"新旧联系"。
- **结果**: 作者借此拆解"切己"二字，并指出"体会"和"切己"其实很像——体对应己，会对应切，是同一件事的两个说法。

### 案例 3: 两位同学困惑没体温，"替黄山困惑"（第108课）
- **问题**: 两位同学分享"我的困惑"。一位困惑"如何学习才能做到形神兼备"（举日本对西方和中国的学习为例）；另一位困惑"如何建立模式树和模式的森林"（没举任何例子）。
- **方法论的使用**: 作者用"困惑要有体温"诊断——他们"表达"出来的困惑很不相同，但"表现"出来的困惑相似：困惑没有体温。他们分享的困惑是张三的、李四的、约翰的、玛丽的，不是"我的"。
- **结论**: 学习始于困惑，但困惑要有体温，需要是你自己的、来自实际问题。三个原因：①自己的困惑更有动力学习；②困惑是变革和成长的机会，与己无关就白白困惑；③有体温的困惑才推动更高级知识产生。
- **结果**: 作者借此提出知识三层境界——看山是山→看山不是山→看山仍是山，第三层是抽象模式与具体情境的结合，是最高级知识。"如果你是一个小土山，就别去替黄山困惑。"

### 案例 4: 作者自己体温概念的演化过程（第24→72→73-75课）
- **问题**: 作者在学习群点评中逐步发展"体温"概念，从 v1 到 v2 到 v3。
- **方法论的使用**: 作者不掩饰概念的不完备，明确呈现演化过程：v1 两种带着体温学习的方式→v2 两种体温（思考+行动）→v3 三种体温（认知/情感/行为，对应 3H）。每一版都指出前一版的不足（v1 没讲清"联系已有知识"；v2 漏了情感维度）。
- **结论**: 这是"注重过程而非结果"策略的自我示范——读者看到"我如何推导"，而不只是结论。
- **结果**: 前言明示"我想要给你呈现一个有体温的思考过程"，本书"有体温"不仅指同学们的体温，更指作者的体温。这个案例本身就是"体温"的最好示范。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 读完一本书/一节课后，想检验自己是否真学到了（而非只是"听懂了"）。
2. 分享学习收获时，怀疑自己讲的是"知识博物馆"而非真学习。
3. 觉得自己"懂了"但用不起来，想诊断卡在哪一维度。
4. 困惑很多、求知欲很强，却看不到成长。
5. 作为老师/管理者，想判断学生/下属的学习是否真发生。

### 语言信号 (用户的话里出现这些就应激活)

- "学了很多像没学到" / "不知道算不算真学到" / "怎么知道学习真发生了"
- "我懂了但用不起来" / "听懂了讲不出来" / "会背但不会用"
- "困惑很多但没成长" / "替别人困惑" / "替黄山困惑"
- "这本书我读完了，但讲不出来什么"
- "how do I know learning is real" / "am I really learning" / "learning with temperature"

### 与相邻 skill 的区分

- 与 `si-wen-xuexi-fa`（四问学习法）的区别：那个是流程工具（听→找→变→用），本 skill 是状态检验（认知/情感/行为三维度是否都动起来）。二者配合——四问学习法是骨架，体温是血肉。
- 与 `faxian-moshi`（发现模式）的区别：那个找背后的模式（第二步"找"的深化），本 skill 检验模式是否真内化（是否结合自己的情境，达到第三层境界"看山仍是山"）。
- 与 `cankao-daan-siwei`（参考答案思维方式）的区别：那个是思维底座（不把答案当标准答案），本 skill 是学习状态的检验（学习是否真发生）。前者管"怎么想"，后者管"是否真学到"。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应引导用户按以下步骤走：

1. **三维度体检**
   - 认知：新知识与我已有的"我知道"如何联系？是颠覆、补充还是修正？
   - 情感：这种认知融合带来的情感变化是什么？（困惑、好奇、喜悦、抗拒？）
   - 行为：应有的行为与我以前/现在的行为有何不同？情感在多大程度上阻碍了行为转变？
   - 完成标准：三个维度都能给出具体回答，而不是只介绍知识和做法。
   - 🔴 检查点：任一维度用户答不出具体回答（只罗列知识/做法），该维度体温不足——必须在本步补出具体回答（问"这和你已有的什么知识/什么情感/什么行为有联系"）再进下一步，不要跳过。

2. **切己检查**
   - 己：我举了自己的例子吗？谈的是自己的实际问题吗？
   - 切：我在别人知识与自己问题间建立了认知/情感/行为联系了吗？讲了以前自己的认知和困惑吗？别人的知识如何解开我的困惑？
   - 完成标准：能说出"我以前以为 X，听了 Y 之后发现 Z，所以现在打算 W"这样的完整链条，而非只复述别人的话。
   - 🔴 检查点：若只能讲遥远例子（谷歌、刘备）或只罗列书本内容，判定为"天文学家式学习"——回到第一步先找自己的实际问题，不从切己直接进入境界定位。

3. **三层境界定位**
   - 第一层（看山是山）：我学到的还只是具体情境中的经验知识（碎片）吗？
   - 第二层（看山不是山）：我能抽象出脱离情境的模式吗？
   - 第三层（看山仍是山）：我能把抽象模式与自己的具体情境结合起来吗？
   - 完成标准：能定位自己处在哪一层，并能说出迈向下一层需要做什么。最高目标是第三层。
   - 判停条件：若用户自判"第三层"却说不出"抽象模式如何结合我的具体情境"，是伪第三层——退回第二层重做，要求先能脱离情境抽象出模式，再与情境结合。

4. **体温不足时的补救**
   - 认知维度不足：问"这和我已有的什么知识有联系？"
   - 情感维度不足：问"这个知识让我对什么人/事产生了什么新的情感？"
   - 行为维度不足：问"我以前怎么做，现在打算怎么做？"
   - 通用补救：举自己的例子 + 联系实际问题。
   - 完成标准：能用第109课的两个提升体温的问题回答——"这对我有什么用？""我能举个自己的例子吗？"
   - 判停条件：若通用补救后仍答不出这两个问题，说明用户可能处于"初次接触新领域还没旧可对照"或"纯信息查询"——回 B 段边界判断，停止体温检验，先去做垒基学习（见 `moshi-jujiao-xuexi`）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **纯信息查询**：用户只是想知道某个事实（"这本书作者是谁"），不需要体温检验。
- **机械记忆**：背单词、记公式等机械记忆任务，体温是负担。
- **初次接触新领域**：还没有"旧"可对照，三维度互动无从谈起——先做垒基学习（见 `moshi-jujiao-xuexi`）。
- **情绪倾诉**：用户在情绪中，需要共情而非流程化诊断。

### 作者在书中警告的失败模式

- **学习没有体温**（ce16，第72/75/89/108课）：只介绍知识和做法，没有讲新旧认知如何联系、情感如何变化、行为如何转变。"像看体温计度数而非感受体温"——看到知识和做法的罗列，却看不到一个活生生的学习过程。作者明确说："我怀疑是否真的有学习发生，至少，我怀疑是否有深刻的学习发生。"
- **不切己**（ce17，第90/113课）：要么只谈抽象问题不联系自己（"己"不够，如困惑"如何提出好问题"这种宏大问题），要么只讲自己的情况不联系抽象知识（"切"不够，变成"空谈实际"）。困惑过于宏大不切己，或过于具体缺少"切"的动作。作者引述："永生永世不谈不切己的问题。永生永世不以不切己的方式谈论问题。"
- **假顿悟**（ce29，第26/91课）：把听到一个"知识金句"的兴奋当成顿悟。经常"顿悟"但其实都是假的——"你不是醍醐灌顶，你是糨糊灌顶。"学到的是谈资而非改变。真正的顿悟必须能"用"（改变认知或行动），不能"用"的顿悟不是真顿悟。
- **天文学家式学习 / 空谈理论**（ce03，第18/25/26课）：只谈离自己很遥远的例子（谷歌、刘备）或只谈书本上说了什么，不联系自己的实际。"讨论半天别人不知道他是做什么的"——这就是天文学家的证据。作者判断标准：如果你跟别人讨论学习，讨论半天后别人不知道你的职业，那么你还不太会学习。

### 作者的盲点 / 时代局限

- **"体温"是作者独创的隐喻，非学术术语**——借身体温度隐喻学习中"新旧互动"的状态。在学术语境中需用日常语言解释，不能当作严谨概念套用。作者自己承认这个概念在书中经历了三次演化，并非定型结论。
- **3H 模型借用自英文学习理论界**，作者区分三个不同版本（分别发展 / 同时调用 / 共同转变），但未充分引用原始文献，学术严谨性不足。作者自己也说"我读了几篇关于学习的 3H 模型的论文，发现它们说的不完全是一回事"。
- **案例多为企业管理者/创业者/职场人**，对学生、蓝领、自由职业者、退休人群的适用性需用户自行迁移。
- **对学校教育的简化批评**：作者多处将学校教育简化为"为考试"，忽视学校在系统知识结构、社会化、批判思维训练上的价值。

### 容易混淆的邻近方法论

- **心流（flow，契克森米哈伊）**：描述专注投入的状态，强调技能与挑战匹配；体温不强调专注，而强调新旧认知/情感/行为的"纠缠互动"。心流是状态描述，体温是学习发生机制。一个人可以心流地背完一本书，但若没有新旧互动，仍是没体温的学习。
- **具身认知（embodied cognition）**：学术理论，强调身体在认知中的核心作用；体温是学习论概念，包含身体但不限于身体（情感也是体温的一部分）。作者 v1 版本接近具身认知，v3 版本已扩展到认知/情感/行为三维度。
- **库伯学习圈（Kolb's cycle）**：具体经验→反思观察→抽象概念化→主动实践；与本 skill 的三维度有交集，但库伯强调循环（四阶段），体温强调"新旧纠缠互动"（三维度同时发生），不是阶段而是状态。
